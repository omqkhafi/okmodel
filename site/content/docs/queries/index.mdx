The table is declared. [First schema](/docs/start/first-schema) covers insert, find, one, count, exists, update, and delete. These pages are the rest of the surface.

`one` returns the row or `null`. More than one match is `not_unique`: `one() on notes matched more than one row. Pass orderBy to take the first, or narrow where.` A caller-supplied filter goes through [filters](/docs/queries/request-filters).

## I want to …

| --- | --- | --- |
| Read several rows | `find` | [Read rows](/docs/queries/read-rows#find) |
| Read one row or `null` | `one` | [Read rows](/docs/queries/read-rows#one) |
| Count matching rows | `count` | [Read rows](/docs/queries/read-rows#count) |

| Page with a cursor | `page` | [Read rows](/docs/queries/read-rows#page) |
