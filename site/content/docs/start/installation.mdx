Install OKModel, point it at Postgres, and open a client.

You need Bun 1.4+ (the examples use Bun commands) or Node.js 22.18+, and a Postgres 15 or newer server. OKModel itself runs on both runtimes. `Bun.sql` works only on Bun. `okm` is the CLI bin shipped with the package (`bunx okm …`).

## Files this page writes

| File | Role |
| --- | --- |
| `schema.ts` | The table definitions and `schema()` export |
| `db.ts` | `connect` and the exported `db` client |
| Later: `okmodel.config.ts` | Tooling config for `okm` ([First schema](/docs/start/first-schema)) |

## Postgres

If you have no server yet, start one:

```sh
docker run -d --name okm-pg -e POSTGRES_PASSWORD=okm -e POSTGRES_USER=okm -e POSTGRES_DB=okm -p 5432:5432 postgres:17
```

`DATABASE_URL` is the connection string. In a shell:

```sh
export DATABASE_URL=postgres://okm:okm@127.0.0.1:5432/okm
```

In `.env` (loaded by your runtime or process manager; `okm` and Node do not invent a loader):

```text title=".env"
DATABASE_URL=postgres://okm:okm@127.0.0.1:5432/okm
```

The database may be empty. PGlite needs no URL and no server; its tab below skips this variable.

<Step>
### Install

`okmodel` has no runtime dependencies. Each driver is an optional peer. Pick the one the runtime already has: postgres.js on Node or Bun when you want the default server driver; node-postgres when `pg` is already installed; Bun.sql only on Bun with no extra package; PGlite when you want Postgres in-process with no server. The pages after this one use postgres.js.

<Tabs items={["postgres.js", "node-postgres", "PGlite", "Bun.sql"]}>

<Tab value="postgres.js">

The default on Node and Bun. It connects to a Postgres server.

```sh title="postgres.js"
bun add okmodel postgres
```

```ts title="driver.ts"
import { connect } from "okmodel/pg/postgresjs";
```

</Tab>

<Tab value="node-postgres">

The other server driver on Node and Bun, when `pg` is already installed. `pg` ships no types, so `@types/pg` is a dev dependency.

```sh title="node-postgres"
bun add okmodel pg
bun add -D @types/pg
```

```ts title="pg-driver.ts"
import { connect } from "okmodel/pg/pg";
```

</Tab>

<Tab value="PGlite">

Postgres runs in the process, on Node or Bun. There is no server to start and no `DATABASE_URL`. The connect target is a data directory, or omit it for memory.

```sh title="PGlite"
bun add okmodel @electric-sql/pglite
```

```ts title="pglite-driver.ts"
import { connect } from "okmodel/pg/pglite";
```

```ts title="pglite-db.ts"
import { connect } from "okmodel/pg/pglite";

import schema from "./schema.ts";

// No DATABASE_URL. "./data" is a directory, or omit the first argument for memory.
export const db = await connect("./data", {
  schema,
  limits: { find: 100, include: 20, page: 50, groupBy: 500, max: 1000 },
});
```

</Tab>



<Step>
### Save the schema

Put this next to `db.ts`. [First schema](/docs/start/first-schema) explains each line.

```ts title="schema.ts"
import { schema, table, t } from "okmodel/pg";

export const notes = table("notes", {
  id: t.identity().primaryKey(),
  title: t.text(),
});

export default schema({ tables: [notes] });
```

</Step>

<Step>
### Connect

For a server driver, `connect` takes the URL and the schema. Keep `db` for the process. `connect` does not read the environment, so `db.ts` checks `DATABASE_URL` itself and throws `DATABASE_URL is not set` when it is missing or empty. The options are on [Connect](/docs/operate/connect). `limits` sets the default `limit` for reads that omit one; without it, such a read is refused. [Query limits](/docs/operate/query-limits).

```ts title="db.ts"
import { connect } from "okmodel/pg/postgresjs";

import schema from "./schema.ts";

const url = process.env.DATABASE_URL;
if (url === undefined || url.length === 0) {
  throw new Error("DATABASE_URL is not set");
}

// Opt-in defaults for reads that omit limit.
// find: find, descendants, ancestors. include: to-many include.
// page: page(). groupBy: grouped aggregate. max: ceiling for a written limit.
// .all(reason) reads past them. A limit on the call wins.
export const db = connect(url, {
  schema,
  limits: { find: 100, include: 20, page: 50, groupBy: 500, max: 1000 },
});
```

PGlite uses the `pglite-db.ts` form in its tab above, not this file.

</Step>

<Step>
### Startup check

`db.connected` resolves when the check finishes. A query waits for it. The check is [Startup check](/docs/operate/startup-check).

```ts title="check.ts"
import { db } from "./db.ts";

await db.connected;
console.log("connected");
await db.close();
```

```text title="connected.out"
connected
```

On an empty database the promise resolved, and the script printed `connected`.

</Step>
