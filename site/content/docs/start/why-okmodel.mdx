---
title: "Why OKModel"
description: "What this version gives you, and what it does not."
---
As of 0.10.0.

The schema is the single source for types, queries, and migrations ([Introduction](/docs/start)). [`schema()`](/docs/schema/the-schema) compiles the tables. Queries are the calls on [Queries](/docs/queries). Migrations are generated from that schema ([generate](/docs/reference/cli#generate)).

The majors are PostgreSQL 15, 16, 17, and 18 ([Minimum Postgres](/docs/schema/the-schema#minimum-postgres)). The test suite runs on 15, 16, 17, and 18 ([Drivers](/docs/operate/drivers)).

`okmodel` has no runtime dependencies. Each driver is an optional peer ([Installation](/docs/start/installation)).

postgres.js, node-postgres, Bun.sql, and PGlite are the columns in the conformance table. Neon is not a column in that table ([Compatibility](/docs/reference/compatibility), [Drivers](/docs/operate/drivers)). `okm driver test <driver>` runs the conformance suites ([driver test](/docs/reference/cli#driver-test), [compatibility.test.ts](https://github.com/omqkhafi/okmodel/blob/main/tests/compatibility.test.ts), [driver-conformance.test.ts](https://github.com/omqkhafi/okmodel/blob/main/tests/driver-conformance.test.ts)).

Node.js 22.18 or newer loads the config ([CLI](/docs/reference/cli)). Bun 1.4 or newer is the floor for `okmodel/pg/bun` ([driver test](/docs/reference/cli#driver-test), [Known limits](https://github.com/omqkhafi/okmodel/blob/main/docs/known-limits.md)).

Deno is not supported ([D297](https://github.com/omqkhafi/okmodel/blob/main/docs/okmodel-decisions.md), [Known limits](https://github.com/omqkhafi/okmodel/blob/main/docs/known-limits.md)).

What this version does not do is the list in [Known limits](https://github.com/omqkhafi/okmodel/blob/main/docs/known-limits.md).
