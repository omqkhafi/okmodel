Vercel has no separate example. Use the [Next.js](/docs/frameworks/nextjs) app on the **Node.js** runtime on Fluid compute. This page covers deployment only.

## Runtime and driver

Same as Next.js: Node.js, `okmodel/pg/postgresjs`, example in `examples/nextjs`.

## Deploy

1. Point the Vercel project at `examples/nextjs` (or copy its `app/` and `src/` into your app).
2. Set `DATABASE_URL` (and any migrate target URLs) in the project environment.
3. Keep route handlers on `export const runtime = "nodejs"`. Do not switch those routes to Edge.
4. Build with Bun locally the same way CI does: `bun install` then `bunx next build`.

## Migrate on deploy

Run migrate in a job that has TCP to Postgres before or as the deployment goes live:

```sh
bunx okm migrate apply --target production
```

Protect production with `okm protect` when that target must refuse unsafe plans.

## Gotchas

- Edge functions cannot use the postgres.js TCP driver.
- Fluid compute keeps a Node process warm; the process-scoped client in `src/db.ts` matches that model.
- Deno is unsupported. D1 has no adapter.
