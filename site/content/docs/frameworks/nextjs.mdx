Use OKModel from App Router route handlers on the **Node.js** runtime.

## Runtime and driver

| | |
| --- | --- |
| Runtime | Node.js 22.18+ (Bun for install and scripts) |
| Driver | `okmodel/pg/postgresjs` + `postgres` |
| Example | `examples/nextjs` |

## Install

```sh
bun add okmodel postgres
bun add -D @types/node
```

## `db` module and lifecycle

One client per Node process. In `next dev`, pin it on `globalThis` so Fast Refresh does not open a new pool on every remount.

```ts title="src/db.ts"
import { connect } from "okmodel/pg/postgresjs";
import { app } from "./schema";

const globalDb = globalThis as { __okmDb?: ReturnType<typeof connect> };

export const db =
  globalDb.__okmDb ??
  connect(process.env.DATABASE_URL!, { schema: app });

if (process.env.NODE_ENV !== "production") globalDb.__okmDb = db;
```

## Routes

```ts title="app/api/notes/route.ts"
import { NextResponse } from "next/server";
import { db } from "../../../src/db";

export const runtime = "nodejs";

export async function GET() {
  return NextResponse.json(await db.example_notes.find({ limit: 50 }));
}

export async function POST(request: Request) {
  const body = (await request.json()) as { title?: string };
  const row = await db.example_notes.insert({
    title: body.title ?? "untitled",
  });
  return NextResponse.json(row, { status: 201 });
}
```

## Dev and test

```sh
bun run build          # repository root, once
bun run db:up
bun install --cwd examples/nextjs
bunx --cwd examples/nextjs next dev --port 3104
bun test examples/nextjs/nextjs.test.ts
```

## Deploy and migrate

Deploy on the Node.js runtime (Vercel Fluid compute uses that same example; see [Vercel](/docs/frameworks/vercel)). Run `bunx okm migrate apply` against the target database in your release job before or as the deploy starts. Do not open a client at module evaluation in an edge bundle.

## Gotchas

- Set `export const runtime = "nodejs"`. The Edge runtime has no TCP driver here.
- Hot reload can remount `db.ts`; keep the `globalThis` guard in development.
- Deno is unsupported (D297). D1 has no adapter.

## Verification

**CI** — `examples/nextjs/nextjs.test.ts` builds the app, starts it, and calls `GET`/`POST /api/notes` against the repository Postgres topology.
