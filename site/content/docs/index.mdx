The schema is the source. Migrations and queries come from it. Start with one table, then add only the part you need.

Tooling around that schema: [pull](/docs/reference/cli#pull) writes table files from a database, [import drizzle](/docs/migrations/from-drizzle) writes them from a Drizzle schema, [catalogs](/docs/schema/several-catalogs) share one database, [describe](/docs/reference/schema-api) returns the catalog as JSON, [extension packs](/docs/schema/extensions) cover the contrib set except `vector`, the [GitHub Action](/docs/reference/github-action) posts the plan, and a [type change](/docs/migrations/type-change) that rewrites a table is five migrations.

<Callout title="The source">
  The tables you declare are the catalog. Queries, migrations, and checks come from that catalog.
</Callout>

```ts title="schema.ts"
import { table, t } from "okmodel/pg";

export const notes = table("notes", {
  id: t.identity(),
  title: t.text(),
});
```
