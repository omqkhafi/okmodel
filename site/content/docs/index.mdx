okmodel is a TypeScript ORM for PostgreSQL 15 to 18 with no runtime dependencies. One schema gives you typed queries and reviewed migrations, and calls with no limit or no filter are refused.

A new project starts at [Installation](/docs/start/installation). An existing database starts at [Existing database](/docs/migrations/adopt-existing-database) or [From Drizzle](/docs/migrations/from-drizzle). To find an answer, open [Schema](/docs/schema/tables), [Queries](/docs/queries), [Migrations](/docs/migrations/type-change), [Operate](/docs/operate/connect), or [Reference](/docs/reference/cli). How the pieces fit is [How it works](/docs/concepts/how-okmodel-works).
