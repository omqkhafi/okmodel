okmodel is a TypeScript ORM for PostgreSQL 15 to 18 with no runtime dependencies. One `schema()` gives typed queries and reviewed migrations, and a read with no `limit` or a write with no `where` is refused.

```ts title="schema.ts"
import { schema, table, t } from "okmodel/pg";

export const notes = table("notes", {
  id: t.identity().primaryKey(),
  title: t.text(),
});

export default schema({ tables: [notes] });
```

```ts title="find.ts"
import { connect } from "okmodel/pg/postgresjs";

import schema from "./schema.ts";

export async function sample(url: string) {
  await using db = connect(url, { schema });
  return await db.notes.find({ where: { id: "1" }, limit: 1 });
}
```

```text title="find.out"
[
  {
    id: "1",
    title: "Hello",
  }
]
```

Without `limits` on `connect`, omitting `limit` is [OKM1101](/docs/reference/errors#okm1101): `find() needs a limit.` [Query limits](/docs/operate/query-limits) is the opt-in default.
