Add `okmodel` and one Postgres driver. Another database is a later section on this page. The next page defines a table.

| Driver | Package | Runs on | Server |
| --- | --- | --- | --- |
| postgres.js | `postgres` | Node and Bun | A Postgres server. The default. |
| node-postgres | `pg` | Node and Bun | A Postgres server, when `pg` is already installed. |
| PGlite | `@electric-sql/pglite` | Node and Bun | In the process. No server to start. |
| Bun.sql | none | Bun | A Postgres server. Node cannot load it. |

## Postgres

`okmodel` has no runtime dependencies. Each driver is an optional peer. Pick the one the runtime already has.

### postgres.js

The default on Node and Bun. It connects to a Postgres server.

```sh title="postgres.js"
bun add okmodel postgres
```

```ts title="db.ts"
import { connect } from "okmodel/pg/postgresjs"; // [!code focus]
```

### node-postgres

The other server driver on Node and Bun, when `pg` is already installed. `pg` ships no types, so `@types/pg` is a dev dependency.

```sh title="node-postgres"
bun add okmodel pg
bun add -D @types/pg
```

```ts title="db.ts"
import { connect } from "okmodel/pg/pg"; // [!code focus]
```

### PGlite

Postgres runs in the process, on Node or Bun. There is no server to start. The connect target is a data directory, or omit it for memory.

```sh title="PGlite"
bun add okmodel @electric-sql/pglite
```

```ts title="db.ts"
import { connect } from "okmodel/pg/pglite"; // [!code focus]
```

### Bun.sql

Built into Bun. No extra package. This entry does not run on Node. `bunx okm` still uses Node. `bun --bun okm` is the Bun runtime.

```sh title="Bun.sql"
bun add okmodel
```

```ts title="db.ts"
import { connect } from "okmodel/pg/bun"; // [!code focus]
```
