`reference` declares rows the application needs. Apply inserts a row when its key is missing. It does not update or delete. The rows stay on the schema. They are not a diff in the catalog.

```ts title="statuses.ts"
import { table, t } from "okmodel/pg";

export const statuses = table(
  "statuses",
  {
    code: t.text().primaryKey(),
    label: t.text(),
  },
  {
    reference: {
      key: "code",
      rows: [
        { code: "open", label: "Open" },
        { code: "done", label: "Done" },
      ],
    },
  },
);
```

`key` is one column name or several, in constraint order. `rows` are the values. Each value is a string, a number, a boolean, or null.
