A preset is a named refinement you call on the table: `notes.pending()`. It receives a builder and returns that builder. The only method is `where`. It adds a predicate. It cannot remove or replace one.

```ts title="notes.ts"
import { table, t } from "okmodel/pg";

export const notes = table(
  "notes",
  {
    id: t.identity(),
    title: t.text(),
    status: t.text(),
  },
  {
    presets: {
      pending: (q) => q.where({ status: "pending" }),
    },
  },
);
```

A name that is a client method, or a reserved name such as `find`, `insert`, or `then`, is OKM1040. The same list is a type error on the option.

The tenant predicate and an active set are not in the builder. The planner puts them around the preset.

A trait can add presets too. The table's own names are applied first.
