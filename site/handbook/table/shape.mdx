`.array()` wraps a scalar. `dims` defaults to 1 and must be an integer from 1 to 6. Calling it on a column that is already an array is refused.

`.picklist()` narrows a string column to a literal union. The catalog gets a CHECK unless you pass `{ check: false }`. An empty list, an empty value, or a repeated value is OKM1060. A default that is not in the list is refused. A value outside the list is rejected when it is encoded.

```ts title="notes.ts"
import { table, t } from "okmodel/pg";

export const notes = table("notes", {
  id: t.identity(),
  tags: t.text().array(),
  status: t.text().picklist(["open", "done"]).default("open"),
});
```

`array({ dims: 2 })` is a matrix. The rank starts at 1. There is no second `.array()` call to add a dimension.
