The field name is the TypeScript name. The SQL name defaults to that field, or to snake_case when the schema sets [casing](/docs/schema/casing). `sqlName` replaces it. `renamedFrom` is the previous SQL name migrations read. `comment` is stored beside the object.

```ts title="notes.ts"
import { table, t } from "okmodel/pg";

export const notes = table(
  "notes",
  {
    id: t.identity(),
    title: t.text().sqlName("headline").comment("Shown in the list"),
  },
  {
    sqlName: "note",
    renamedFrom: "posts",
    comment: "One row per note",
  },
);
```

An empty `sqlName`, `renamedFrom`, or table comment is refused. A column comment may be empty only in the sense that you omit the call. The text you pass is stored as given.
