`.references()` points a column at another table. The argument is the table name, so the column type does not cycle. `schema()` checks that the table exists (OKM1020).

```ts title="comments.ts"
import { table, t } from "okmodel/pg";

export const comments = table("comments", {
  id: t.identity(),
  noteId: t.bigint().references("notes", { onDelete: "cascade" }),
  body: t.text(),
});
```

`onDelete` and `onUpdate` are `"cascade"`, `"no action"`, `"restrict"`, `"set default"`, or `"set null"`.

`columns` names the target columns when the key is not the primary key. At least one name. Empty names are refused.

A [relation](/docs/table/relations) is the name you query. The reference is the foreign key. You want both: the column stores the key, and `one` or `many` names the edge.
