Schema [tenancy](/docs/schema/tenancy) adds the key to every table. Two opt-outs live on the table.

`global("reason")` keeps the tenant column off this table. The reason is required.

`via("project.organization")` isolates through relations instead of a column on this table. The path is steps separated by `.`, up to three.

```ts title="audit.ts"
import { table, t } from "okmodel/pg";
import { global, via } from "okmodel/tenancy";

export const plans = table(
  "plans",
  { id: t.identity(), code: t.text() },
  { tenancy: global("plans are shared") },
);

export const tasks = table(
  "tasks",
  {
    id: t.identity(),
    projectId: t.uuid().references("projects"),
    title: t.text(),
  },
  { tenancy: via("project.organization") },
);
```

`global` and `via` come from `okmodel/tenancy`. A unique on a tenant table includes the key unless `.unique({ global: "reason" })` says otherwise.
