<Callout type="info" title="Where this fits">
The table is declared. A preset names a `where` you would otherwise repeat, such as `notes.pending()`.
</Callout>

A preset receives a builder and returns that builder.

### where

`where` is the only method. It adds a predicate. It cannot remove or replace one.

```ts title="notes.ts"
import { table, t } from "okmodel/pg";

export const notes = table(
  "notes",
  {
    id: t.identity(),
    title: t.text(),
    status: t.text(),
  },
  {
    presets: {
      pending: (q) => q.where({ status: "pending" }), // [!code focus]
    },
  },
);
```

<Callout type="info" title="Around the preset">
The tenant predicate and an active set are not in the builder. The planner puts them around the preset.
</Callout>

### Reserved names

A name that is a client method, or `find`, `insert`, or `then`, is refused. The same list is a type error on the option.

<Callout type="error" title="OKM1040">
Pick a name that is not already a method on the client.
</Callout>

### Trait names

A trait can add presets too. The table's own names are applied first.
