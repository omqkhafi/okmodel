<Callout type="info" title="Where this fits">
An [index](/docs/define/table/indexes) does not reject a row. A check does.
</Callout>

A check is named SQL. The function receives column handles. This is not a query builder.

### Name

The object key is the constraint name.

### Expression

`sql` interpolates a handle as its SQL name. The database normalises the expression later.

| Field | Required | Role |
| --- | --- | --- |
| name | yes | The constraint name. |
| function | yes | Receives column handles and returns the expression. |

```ts title="notes.ts"
import { sql, table, t } from "okmodel/pg";

export const notes = table(
  "notes",
  {
    id: t.identity(),
    title: t.text(),
  },
  {
    checks: {
      title_present: (columns) => sql`${columns.title} <> ''`, // [!code focus]
    },
  },
);
```

<Callout type="info" title="SQL name">
A handle becomes the SQL name `schema()` stores, including [casing](/docs/define/schema#casing).
</Callout>
