A table is a name, its columns, and the relations you want the client to follow. Declaring it is what makes the client typed. A unique or a foreign key is spelled from the SQL column names, so a rename of the column's SQL name renames the constraint and does not drop it.

## Declare the table

<Tabs items={["Identity", "Relation"]}>

<Tab value="Identity">

`t.identity()` is the primary key. An insert leaves `id` out. The row comes back with it, as a string.

```ts title="schema.ts"
import { schema, table, t } from "okmodel/pg";

// The insert leaves id out. The row comes back with it as a string.
const authors = table("authors", { id: t.identity(), name: t.text() });
export const app = schema({ tables: [authors] });
```

`t.identity({ as: "number" })` is the same key, and the id comes back as a number.

</Tab>

<Tab value="Relation">

`authorId` points at `authors`. `one` and `many` name the two directions. A query can then include the author on a note. A to-many include takes a limit, and that limit is the first related rows of each parent. A column that references its own table is the parent `descendants` walks.

```ts title="schema.ts"
import { many, one, schema, table, t } from "okmodel/pg";

const authors = table(
  "authors",
  { id: t.identity() },
  { relations: { notes: many("notes", "authorId") } },
);
const notes = table(
  "notes",
  { id: t.identity(), authorId: t.bigint().references("authors") },
  { relations: { author: one("authors", "authorId") } },
);
export const app = schema({ tables: [authors, notes] });
```

</Tab>

</Tabs>

## Traits

`versioned()` adds `version`. An update passes the version you read, and a stale write is a conflict. `sortable("laneId")` adds `position`. New rows go at the end of that lane. `move` places a row before or after another in the same lane.

```ts title="schema.ts"
import { schema, table, t } from "okmodel/pg";
import { sortable, versioned } from "okmodel/traits";

const tasks = table(
  "tasks",
  { id: t.text().primaryKey(), title: t.text(), laneId: t.text() },
  { traits: [versioned(), sortable("laneId")] },
);
export const app = schema({ tables: [tasks] });
```
