`functions` lists routines. `fn()` comes from `okmodel/fn`. `schema()` stores the catalog record. It does not run the body.

```ts title="schema.ts"
import { fn } from "okmodel/fn";
import { schema, sql, table, t } from "okmodel/pg";

const notes = table("notes", {
  id: t.identity(),
  title: t.text(),
});

const touch = fn("touch_notes", {
  returns: "trigger",
  language: "plpgsql",
  body: sql`begin return new; end`,
  dependsOn: [notes],
});

export default schema({
  tables: [notes],
  functions: [touch],
});
```

`language` is `"sql"` or `"plpgsql"`. `volatility` is `"volatile"`, `"stable"`, or `"immutable"`. `security` is `"invoker"` or `"definer"`.

plpgsql without `dependsOn` is OKM1824. Postgres does not record dependencies inside that body. `security: "definer"` without `searchPath` is OKM1823.

`LANGUAGE sql` that begins with `BEGIN ATOMIC` can omit `dependsOn`. Those edges are read from `pg_depend`.

A [trigger](/docs/schema/triggers) calls one of these functions.
