`requires.postgres` is the engine this schema is written for. Connect records it.

```ts title="schema.ts"
import { schema, table, t } from "okmodel/pg";

const notes = table("notes", {
  id: t.id({ default: "uuidv4" }),
  title: t.text(),
});

export default schema({
  tables: [notes],
  requires: { postgres: "15" },
});
```

An undeclared `requires` does not name a version, so a `uuidv7()` default stays. A declared version older than 18 refuses `uuidv7()`.
