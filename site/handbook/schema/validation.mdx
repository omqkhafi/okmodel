`validation` turns rules on for the schema. `schema()` stores the flag. It does not run the rules. `okm check` reads them, and the engine reads them on the first validated call.

```ts title="schema.ts"
import { schema, table, t } from "okmodel/pg";

const notes = table("notes", {
  id: t.identity(),
  title: t.text(),
});

export default schema({
  tables: [notes],
  validation: { enabled: true, onRead: false, style: "inline" },
});
```

`true` enables it. `false` leaves it off. An object takes `enabled`, `onRead`, and `style`. `style` is `"inline"` or `"section"`.

A table can turn the flag on or off with its own `validation`. The rules themselves are [on the table](/docs/table/validation): a `validate` section, or `.validate()` on a column. The same field in both places is OKM1030.
