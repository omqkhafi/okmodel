Four paths. Each one is resolved from the project directory. An absolute path stays absolute. A relative path, including `..`, is resolved from that directory.

| Path | Required | Default | Role |
| --- | --- | --- | --- |
| `schema` | yes | — | The module that exports the schema. |
| `tables` | no | — | A directory of table files. |
| `migrations` | no | `migrations` | Generated SQL. |
| `out` | no | `.okm` | Build output. |

## schema

`okm` loads this file. `okm build` reads it and does not connect.

```ts title="okmodel.config.ts"
import { defineConfig } from "okmodel/migrate";

export default defineConfig({
  schema: "./schema.ts", // [!code focus]
  tables: "./tables",
  migrations: "./migrations",
  out: "./.okm",
  database: process.env.DATABASE_URL!,
});
```

## tables

`okm check` reads every `.ts` file in this directory. A file whose name is missing from the schema module is OKM1024. A name that starts with `.` is skipped. Omit `tables` when every table lives in the schema module.

```ts title="okmodel.config.ts"
import { defineConfig } from "okmodel/migrate";

export default defineConfig({
  schema: "./schema.ts",
  tables: "./tables", // [!code focus]
  migrations: "./migrations",
  out: "./.okm",
  database: process.env.DATABASE_URL!,
});
```

## migrations

`okm generate` writes SQL here. `okm migrate apply` and `okm migrate check` read the same directory. The default is `migrations`.

```ts title="okmodel.config.ts"
import { defineConfig } from "okmodel/migrate";

export default defineConfig({
  schema: "./schema.ts",
  tables: "./tables",
  migrations: "./migrations", // [!code focus]
  out: "./.okm",
  database: process.env.DATABASE_URL!,
});
```

## out

`okm build` writes `catalog.json`, `catalog.hash`, and `types.d.ts` here. The command does not connect. The default is `.okm`.

```ts title="okmodel.config.ts"
import { defineConfig } from "okmodel/migrate";

export default defineConfig({
  schema: "./schema.ts",
  tables: "./tables",
  migrations: "./migrations",
  out: "./.okm", // [!code focus]
  database: process.env.DATABASE_URL!,
});
```
