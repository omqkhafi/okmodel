The schema is the source. Migrations and queries come from it. Start with one table, then add only the part you need.

<Callout title="The source">
  The tables you declare are the catalog. Queries, migrations, and checks come from that catalog.
</Callout>

```ts title="schema.ts"
import { table, t } from "okmodel/pg";

export const notes = table("notes", {
  id: t.identity(),
  title: t.text(),
});
```
