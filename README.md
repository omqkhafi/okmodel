# OKModel

Early stage: the API has not stabilised yet.

OKModel (OKM) is a catalog-first TypeScript ORM. Work in progress.

## Install

Install first. A bare `bunx okm` without installing can fetch an unrelated package.

```sh
bun add -d okmodel
bunx okm
```

Or install globally:

```sh
bun add -g okmodel
```
