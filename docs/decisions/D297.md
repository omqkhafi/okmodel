# D297 — Deno is not supported

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Deno is expected to stop within a year (Ali, 2026-10-18). OKModel does not support it. Supported runtimes are Node, Bun, and an edge or Workers runtime where an adapter exists. CI does not install Deno. `bun run test:runtimes` runs the portable checks on Node and imports the runtime entry as an edge bundle on Node. Bun runs `bun test`. There is no `deno` export condition and no JSR package. No public API change. No new error kind. No catalog hash change. No `src/` change. No gate or ceiling moves. Issue #358
