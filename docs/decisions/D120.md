# D120 — Row types emitted by default

- **Status:** accepted
- **Area:** product
- **Supersedes:** D25

---

`okm build`/`okm dev` emit row types into `.okm/types.d.ts` (config `types: "emitted" or "inferred"`, default emitted); inferred is the zero-build mode; both give the same shapes (CI `expectTypeOf` test). Emitted names derive from table names (`Tasks`, `TasksInsert`, `TasksUpdate`); duplicate table names are rejected (OKM1023), unknown references reported at build (OKM1021). Reason: M0-08, M0-09, M0-12: emitted costs 0 consumer instantiations against 53,410 inferred at 200 tables (43,676 unbranded; ~250 per table). Supersedes the D25 wording; hover quality is unmeasured (D111), so P12 adds a manual editor check
