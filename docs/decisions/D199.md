# D199 — `okmodel/testing` is a real pool, a seeded factory, a statement count, and `okm seed`

- **Status:** accepted
- **Area:** tooling
- **Supersedes:** none

---

`testing(schema, { driver })` returns `{ db, factories, expectQueries, isolation, close }`. The driver is `open()` from `okmodel/pg/pglite` or `open({ url })` from `okmodel/pg/postgresjs`. A `pglite()` helper is not added: it would live on the connect entry, and that graph does not grow for this package. `testing` awaits either a pool or a promise of one. It applies `renderCatalog` before connecting unless `migrate: false`. `okm seed` passes false because the target is already migrated. Factory defaults: a column is required when it is writable, not guarded, has no client `fill`, and is not nullable, defaulted, identity, or generated. The fill is taken from the column type (text, uuid, integer, numeric, boolean, JSON, the first enum label, or a `Temporal` value the column accepts) by asking `column.encode`. A value the codec rejects is not used. If every candidate is rejected, the error names the column. The tenant key is guarded and is the `for()` scope; omitted, it is generated. `x.ref` reuses the latest row of that table in the same tenant, or inserts one. `with({ child: n })` sets the child's foreign key from a `many` relation, otherwise a `one` relation, otherwise the catalog foreign key. Generators are a mulberry32 sequence in this package, no dependency. The default seed is `1`. Seed `0` is shifted so the first step is not a fixed point. The same seed replays the same calls. `create` returns the inserted row as a record, not a recursive row type, so the existing type probes do not gain a factory recursion. `expectQueries` counts statements the wrapped pool sent during `fn`. It does not count transaction control after comments are stripped: `BEGIN`, `START TRANSACTION`, `COMMIT`, `COMMIT WORK`, `END`, `ROLLBACK`, `ROLLBACK WORK`, `ROLLBACK TO`, `SAVEPOINT`, `RELEASE`, `SET TRANSACTION`, `SET LOCAL`, and `SET SESSION CHARACTERISTICS`. A data statement inside `tx` is counted. A mismatch throws kind `invalid` and lists the counted statements. The version check is awaited before the harness is returned, so it is not part of the count. `isolation()` treats a table as tenant when its predicate accepts a scope, skips a table whose rules start with `global `, and lists that reason. It inserts as tenant B and runs `find`, `one`, `count`, `exists`, `include` when a relation exists, `update`, and `delete` as tenant A. A leak names the table, the query, and the row. Column tenancy is the 0.4 strategy. Schema-per-tenant and database-per-tenant are M5. `okm seed <file>` loads a module whose default export is a function and calls it with the harness bound to the selected target. `assertTargetPolicy` runs first, so a protected target is OKM1850 unless `--allow-protected`. Several targets without `--target` are OKM1853. No target, or an unknown name, is OKM1845. The command prints `target <name>` and the factory insert counts. No new error code. The subpath is not imported by the runtime entry, the featureless app, the feature-full app, or the connect entries. No gate, cap, or ceiling moves. Found in P54. Issue #83
