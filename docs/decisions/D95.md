# D95 — Commit position

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Session watermark = WAL position read after commit on the committing connection (`pg_current_wal_insert_lsn()`, an upper bound, safe); replicas are eligible when their replay position reaches it; replay positions are monotonic, so a cached value is a lower bound; position read failure marks the session position-unknown; root client has a conservative client-wide watermark; `consistency: "session"` default, `"eventual"` and `.replica({ consistency })` opt out; position reading is a dialect/engine capability. M0 verifies the mechanism and its cost. Reason: PostgreSQL returns no commit LSN to clients, so the honest mechanism is stated and measured, not assumed **Confirmed by M0, wording amended (D121).**
