# D332 — A rename can be answered at generate without editing the schema

- **Status:** accepted
- **Area:** tooling
- **Supersedes:** none

---

Amends D24. One column removed and one added on the same table is a terminal question. Yes writes `ALTER TABLE … RENAME COLUMN` by passing a `DeclaredRename` into the planner for that run. No writes the drop and the add. `--rename table.old=new` and `--drop-and-add` are the same answers. No terminal and no flag is OKM1530, exit 3, and the fix names the flags. `.renamedFrom` is unchanged. The schema file is not edited. Casing pairs, tables, and ambiguous pairs stay the existing refusal. Tooling only. No new error code or `ErrorKind`. Issue: none filed
