# D244 — A lost connection is a driver code or a connection SQLSTATE (P89C)

- **Status:** accepted
- **Area:** adapters
- **Supersedes:** none

---

`isConnectionFailure` does not read error text. A driver `code` of `CONNECT_TIMEOUT`, `CONNECTION_CLOSED`, `CONNECTION_ENDED`, `CONNECTION_DESTROYED`, `ECONNRESET`, `ECONNREFUSED`, `EPIPE`, `ETIMEDOUT`, or `ERR_POSTGRES_CONNECTION_CLOSED` is lost. A SQLSTATE in class `08` or `57P01`–`57P03` is lost. Any other server SQLSTATE is not lost, whatever the message says, including `53300`. `grant CONNECT on table` (`0LP01`, message `invalid privilege type CONNECT for relation`) and a check named `"no_CONNECT_zz"` (`23514`) reject with that database error. The connection can be used again and it holds no lock. `pg_terminate_backend` stays lost on postgres.js, node-postgres, and Bun.sql. `isConnectionErrno` also treats `ENOTFOUND`, `EHOSTUNREACH`, `ENETUNREACH`, and `EAI_AGAIN` as lost. Message matches in the topology unreachable check are gone. Bun.sql still recognises two exact driver texts that carry no code, `Connection closed` and `connection must be a PostgresSQLConnection`, and stamps SQLSTATE `08006`. A closed pool, and a postgres.js or Bun.sql reserved connection that is already closed, reject with SQLSTATE `08006`. A message-only closed-pool error, with no code and no SQLSTATE, is not lost. node-postgres stamps `code` `CONNECTION_CLOSED` when the client has already emitted `error`, and does not read the query message. No new error kind. No public API change. No catalog hash change. A live session that was misclassified as lost skipped rollback and was not released. Apply uses one connection, so the drain `select 1` waited on that session while it held locks. A backend that is actually gone does not hold locks, and the existing terminate tests already exit. That release path is unchanged. Issue #222 **Amended by D325 (the lost-session check still ignores text; the kind mapper reads `Connection terminated unexpectedly` and `Connection terminated due to connection timeout`).**
