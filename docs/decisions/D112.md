# D112 — Module format

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

The package is ESM only, with TypeScript declarations from `tsc`. There is no CommonJS build and no dual-package hazard; CommonJS consumers use dynamic `import()` or `require()` of ES modules where their Node version supports it. The attw profile is `esm-only` (`node10` and `node16`-from-CJS resolutions are expected to be ignored). Reason: the core is runtime-agnostic and the catalog identity must not exist twice in one process
