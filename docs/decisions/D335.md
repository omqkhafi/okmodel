# D335 — Apply counts empty rows before it changes a required column

- **Status:** accepted
- **Area:** dialects
- **Supersedes:** none

---

Before the first step, a migration that sets a column `NOT NULL` or adds it `NOT NULL` without a fill counts the empty rows on that target. Some rows and no fill stops with OKM1525, says `Nothing was changed.`, and names `--fill` or a later data migration. It does not say to edit a committed migration. A committed migration stopped this way is a known limit. A migration that already has the fill is not checked again. No new `ErrorKind` or exit code. Issue: none filed
