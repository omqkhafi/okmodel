# D173 — P26 ships at +260 / +81; validation fails closed; typed surface by augmentation

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

The redesign of D172 landed: featureless app 87,408 / 29,019 (+260 / +81 over P25, inside the 500 / 150 share, under the gate 87,900 / 29,210), total graph 140,394 / 45,569, engine chunk (8,025 / 3,005) not in it, validating app 92,269 / 30,636 at startup (reported). PR #105, 0.2.0-next.15. Accepted from the four proposals: OKM1030 is `okm check` (and the same function when an app that imported `okmodel/validate` builds a client), not a TypeScript error; the `Input` mark follows the literal `schema({ validation: true })` only for now; `insert.validate`, `check`, `pick`, `omit` and the Standard Schema surface are runtime-only and not on the table type, because adding them measured 17,645 instantiations against the 17,300 ceiling; `insert()` stays typed `Insert` with `InsertBody` carrying `Input`. Two findings from review. (1) Fail-open: the spec text says a schema that stores `validation` without `import "okmodel/validate"` does not run rules, so a forgotten import silently disables validation on writes. Decision: it fails closed. When a schema enables validation (schema or table level, any form) and `okmodel/validate` has not registered, `connect()` throws a new OKM12xx error naming the cause; it never runs unvalidated (same principle as D162, a failed import fails the call). (2) The typed surface should not stay runtime-only, and the 200-table probe is at 17,282 / 17,300 instantiations (0.10% under) and 6,997 / 7,100 types, so P27 cannot add query types without a decision. Decision: P26b moves the `insert.validate` family and the table-level / object-form `Input` mark into a TypeScript module augmentation shipped with `okmodel/validate`, so an app that imports validation gets the types and an app that does not pays nothing in the featureless probe; the probe must not move. Before P27 the probe ceilings get an explicit decision with Ali if P27 needs room. Found in P26
