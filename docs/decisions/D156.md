# D156 — Driver choice by subpath, and what a capability flag means

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

`pg` and `Bun.sql` ship as `okmodel/pg/pg` and `okmodel/pg/bun`; the default stays `okmodel/pg/postgresjs`. `pg` is an optional peer (`^8.16.0`) and Bun.sql has no package; neither import is reachable from the runtime entry. A capability flag is true only where the shared suite passed it, so the table is honest: Bun.sql `cancel`, `describe` and notices are false, node-postgres `describe` is false, and node-postgres cancels through its own 16-byte CancelRequest on a fresh socket because `Client.cancel` corrupts the live connection. All four drivers exit after the last call without `close()` (plain pool); the TLS path of node-postgres is unread because the test tree has no TLS server, and that is written in known-limits. New connect entries print their size and get gates at measured +3% when a prompt sets them. Found in P18
