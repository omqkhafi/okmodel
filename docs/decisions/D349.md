# D349 — Keyed RLS policies, session lists, and SET LOCAL ROLE

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Amends D328 and D343: `table({ policies })` is no longer OKM1061. `policies: () => ({ key: { as?, for?, to?, using?, check?, comment? } })`. The key is the stored name. `for` is one of select, insert, update, delete, or all (default all), one command per policy. `as` is permissive (default) or restrictive. `to` defaults to the `app` role key, never PUBLIC; `to: "public"` is explicit and stores no role list. `using` and `check` are a `where` object, an `expr`, `true` or `false`, or `sql`. `sessionSettings()` returns handles. The compiler prints `(select nullif(current_setting(..., true), '')::type)`. `text[]` reuses `settingList`. `includes(list, value)` prints `value = any (list)` with the cast outside the subselect. `sessionSettings(settings, { role })` runs `set_config('role', name, true)` first. OKM1707 then checks `current_user`. A non-member is 42501 mapped to OKM1923 only when the message is SET ROLE. `columnTenancy`, `compositeTenancy`, and `rlsTenancy` take `uuid \| text \| int \| bigint`. The generated tenant policy is permissive (`as permissive`). User policies on a tenant table must be restrictive (OKM1924). Name clashes with `{table}_tenant` and `{table}_unscoped_select` are OKM1924. SELECT or DELETE with `check`, and INSERT with `using`, are OKM1924. A policy cycle, including a self-read, is OKM1925 before 42P17. `rls: true` enables, `false` disables, `{ force: true }` enables and forces. Absent `rls` with policies enables. `rlsTenancy` stays forced. Lowering enforcement is a contract step (`--allow-protected`). Creating a PUBLIC policy stays expand: OKM1559 requires the step class to match the kind, and create-policy is expand. Drop-policy and disable-rls stay contract. `to`, `using`, and `check` changes are `ALTER POLICY`. `as` or `for` changes drop and create in one transaction. A column type change or a function replace drops and recreates policies that read it. Roles are planned before policies. Undeclared policies on a managed table are drift. OKM does not drop one silently. `okm pull` writes the `sql` form and `import "okmodel/session"`. OKM1550 still flags `USING (true)`, a dropped policy, and a permissive policy on a tenant table. A restrictive policy on a tenant table, and a policy on a table with no tenant policy, are not that weakening. `okm import drizzle` maps `pgPolicy` and `enableRLS` the same way. `okm access` prints what ORs and what ANDs. There is no `okm policies` command. Warnings OKM2110 through OKM2117: leading index, `current_setting` or a function outside `(select ...)`, a security definer that reads a forced table, a bypass role, an unknown `to` role, policies while RLS is off, UPDATE without SELECT, and a restrictive SELECT (INSERT ... RETURNING of a failing row is 42501 while the plain insert works; DELETE ... RETURNING counts fewer rows). INSERT does not use RETURNING by default. Probes and backfills under FORCE refuse with OKM1926 instead of a silent zero, unless the role bypasses RLS or the unscoped select policy can arm `app.unscoped` for a count. A backfill still needs a bypass role. Registry keys: `policies.permissive`, `policies.restrictive`, `session.list`, `session.role`, `tenancy.keyTypes`, `comment.policy`. No new `ErrorKind`. No ceiling moved. `query-200-validate` stays 7,131 types against 7,130, the same number `bun run type-cost` prints on origin/main. Startup, `measureStubbedStartup` in `scripts/size.ts` with dynamic imports stubbed and `postgres` external, of the merged tree (`bb3be727`, Bun 1.4.2) is 97,381 minified and 31,962 gzip. The gates stay 94,680 and 30,850. The tree is over them. This change does not raise them. The runtime entry stays 5,442 and 2,105. postgres.js and PGlite increments stay 16,889 and 12,515. `okmodel/session` (`bun build src/runtime/session/index.ts --target node --minify`) is 13,716 / 5,155 gzip to 39,053 / 13,136 and is not in the featureless startup graph. CLI chunks (`bun build src/tooling/cli.ts --target node --minify --splitting`, sum of the emitted files) are 1,863,326 to 1,890,910 (+27,584). The tarball (`bun run build`, then `bun pm pack --ignore-scripts`) is 1,231,543 to 1,336,367 (+104,824). Issue: none (PR only)
