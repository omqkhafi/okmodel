# D192 — P50 is classification and the linter core; safe rewrites are P50b

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Every plan step kind has one class: `expand`, `contract`, or `unclassified` for raw SQL only. Drop default, a required column with no default, drop identity, `SET GENERATED ALWAYS`, and `ALTER ROLE` are contract. The linter reads the plan and the two catalogs and does not connect. Destructive, backward-incompatible, and data-dependent findings are errors. Locking findings are warnings until P50b emits the safe form, then they become errors. Type preferences are warnings on `okm check`. An override is `-- okm-allow OKM15xx: reason` on the line above the statement. An empty reason, or a code the statement did not trigger, is OKM1510, and an override silences only the code it names. `okm generate` writes the file and prints findings. `okm migrate plan` and `okm check` exit non-zero on an error. `okm migrate apply` re-lints and refuses with OKM1510 before any statement. Safe rewrites (concurrent index create and drop outside a transaction, `NOT VALID` plus `VALIDATE`, `SET NOT NULL` through a validated check, a volatile default split from column creation, a unique constraint built from a concurrent unique index) are P50b. OKM1706 and OKM1823 stay declaration-time until P50b. No gate, cap, or ceiling moves. Found in P50
