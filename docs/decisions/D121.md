# D121 — Commit position confirmed

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

The after-commit position read is confirmed by M0 (`pg_current_wal_insert_lsn()` after commit is 40 bytes past the start of a 34-byte commit record; reading inside the transaction gives the record start, which a replica can reach before applying the commit; `pg_current_wal_lsn()` lags under `synchronous_commit=off`; 0 read-your-writes violations). Cost is one extra statement per write; pipelining (`COMMIT; SELECT ...` as one simple-query message) is optional and evaluated in P13/P63. Fallback rate under write load is measured in P64. Reason: M0-51, M0-55
