# D130 — Column definition and codec errors

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

An invalid column definition (length, precision, scale, array rank, interval qualifier, empty or duplicate picklist or enum values) is OKM1060 at schema construction; a value a codec rejects is OKM1210 at runtime (1200 is the validation range). Messages name the accepted values. No plain `Error` is thrown for these. Found in P11
