# D128 — Catalog error codes

- **Status:** accepted
- **Area:** contracts
- **Supersedes:** none

---

A dependency cycle in the catalog is OKM1026 and a catalog document this version cannot read (unknown version, malformed) is OKM1027; OKM1020 stays "unknown table". Tenant-id sanitizer failures are OKM1122 (identifier rejection), not OKM1120. Check expressions and index predicates are stored as text until P16 normalises them through the database, and renames do not rewrite that text (declared renames in P16 handle references).
