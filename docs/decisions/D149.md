# D149 — Public board is the single source of truth for progress

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

The project is built in the open, so progress lives in one public place, a GitHub Project on the repository, fed by issues and pull requests and updated by automation, not by hand. One issue per roadmap item, in reader language (the internal P-number goes in the body); one milestone per release (0.1.1, 0.2, 0.3, 0.4, 0.5); every pull request body ends with `Closes #N`; the built-in project workflows add new items as Todo, move a pull request to In review, and move an item to Done on merge or close; the release workflow creates the GitHub Release from the changelog section and closes the milestone. The README roadmap links to the board. The decisions and execution-plan documents stay as design records, not status. `okmodel-status.md` stops being updated once the board runs.
