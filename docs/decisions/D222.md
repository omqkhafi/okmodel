# D222 — `refresh()` is not added (P81)

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

§5.7 says to refresh a materialized view with `REFRESH MATERIALIZED VIEW`, that a `refresh()` handle waits for 0.6, and that materialized views own indexes and a `refresh` declaration. `REFRESH ... CONCURRENTLY` needs a unique index (OKM1822). The declaration `refresh: "concurrently"` already exists on `materializedView()`. The section does not define the handle: no arguments, no return type, and no statement of whether a plain view has it. This step does not invent that shape. The SQL form in known-limits stays the way to refresh. Issue #161
