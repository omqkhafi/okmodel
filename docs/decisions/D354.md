# D354 — Size and type cost are reports

- **Status:** accepted
- **Area:** dialects
- **Supersedes:** none

---

Runtime-entry bytes, cold import, app and connect startup graphs, adapter incremental bytes, the CLI chunk sum, tarball size, and type-cost numbers are measurements. The pull-request job `package / size` runs `scripts/size-report.ts` and appends them to the job summary, with deltas against `tests/fixtures/size-report.json`. That file is updated by hand at release prep. The scripts exit 0. There is no ceiling, no `--strict`, and no `--update` for the baseline. `layers-check`, `core-purity`, and `bundle-purity` stay structural guards. `bun run size` still fails when an export keeps an unrelated module. The pack-contract snapshot records the exports map, `bin`, `main`, and the sha256 of each public declaration. It does not record chunk names, chunk counts, or generated error pages. A missing required file or a forbidden file fails without `--update`. No public API change. No new `ErrorKind`. Issue: none (PR only)
