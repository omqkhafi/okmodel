(1) The API surface is classified in `tests/fixtures/api-surface.json` and a new or missing export fails CI; `okmodel` now exports 43 stable names and `okmodel/internal` 69 internal ones, which cut the `okmodel` entry from 24,426 / 8,584 to 5,525 / 2,042 with the app startup graph unchanged (77,537 / 25,625). Rule: an internal export never sits on a public subpath, because editor completions show it on day one and removing it later is a breaking change; `okmodel/pg` still carries 10 internal exports (such as `mapPostgresError`, `emitRowTypes`, `compileColumn`) and `okmodel/migrate` 28, so a short step P17C moves them out before 0.1.0 is tagged, and `okmodel/migrate` keeps only `defineConfig` and its types; the CLI is part of the package and imports its helpers directly. `okmodel/internal` has no stability promise, which the README and the known-limits page say, and its exports carry `@internal`. (2) Docs are tests: the quickstart test extracts the commands from the docs file and runs them verbatim (`okm build`, `okm generate`, `okm migrate apply`, then the read and write calls), so the quickstart cannot drift from what runs; P17B's test applied the generated SQL by hand and so did not exercise `apply`.
