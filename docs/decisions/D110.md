# D110 — Name and npm package

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

The project is named **OKModel** (short **OKM**), published as the unscoped npm package `okmodel`, repository `omqkhafi/okmodel`; CLI bins `okm` and `okmodel` (two thin wrapper files, `dist/okm.js` and `dist/okmodel.js`, written by `scripts/write-bin-wrappers.ts`, because `bun pm pack` lists a file twice when both bins point at one file); error class `OkmError`, codes `OKM1xxx`, config `okm.config.ts`, generated folder `.okm/`, metadata table `okm_meta`. Reason: the name is registrable on npm, short and neutral about the feature set
