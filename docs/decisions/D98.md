# D98 — Target resolution

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Plans and run state hold Target names, never connection details; each Target is resolved at execution time by its resolver; pools are keyed by resolved configuration and capped with LRU eviction; an authentication failure re-resolves once (credential rotation); the registry resolves per role (`app`, `migration`) and may `create(id)` databases
