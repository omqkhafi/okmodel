# D108 — Environments and previews

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

An environment is a named Target: `targets` in `defineConfig` (M1; `database` is the shorthand for `default`), the tenant registry is `tenants`; with several targets `--target` is required (OKM1853); an unprotected target aliasing a protected database is refused (OKM1852). Previews are ephemeral databases created by infrastructure and filled by `migrate apply` from the snapshot (plus optional seed); rehearsal is applying pending migrations to a clone of production; OKModel never drops a database. Reason: nothing about an environment is inferred from `NODE_ENV` or a URL, and a preview must not be able to act on production by omission **Amended by D122 (protection per physical database).**
