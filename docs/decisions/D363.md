# D363 — Mapped errors do not load the catalog compiler

- **Status:** accepted
- **Area:** contracts
- **Supersedes:** none

---

Amends D360 and D361. `schema()` stores a constraint index next to the query model: SQL name, columns, name key, and kind for every constraint and index the descriptors already name, and whether a column is nullable or filled by the database. `mapPostgresError`, `sync`, and the unindexed-computed warning read that index and do not read `.catalog`. Drift calls `compileCatalog` through a dynamic import only when there is no artifact and no `catalog.hash`. A direct `.catalog` read in a bundle with no sibling compiler is still OKM1020. The thrown text is one sentence and `okm help OKM1020`. `armCatalog()` stays the escape hatch for that read. Queries and mapped unique, foreign-key, and check errors do not call it. `okm partitions maintain` refuses a pooled URL with OKM1854, including `--dry-run`, because `DETACH CONCURRENTLY` and `FINALIZE` cannot run through a transaction-mode pooler. There is no `--allow-pooler`. A timestamptz rule without `at` stays OKM1932. A bound that crosses a daylight-saving change is read under UTC and compared as instants. OKM2210 reads `partman.part_config.parent_table`, the primary key. The real table also requires `control`, `partition_interval`, and `partition_type`. No new `ErrorKind`. No catalog hash change.
