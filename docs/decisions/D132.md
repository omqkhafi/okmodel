# D132 — Reserved options and reference names

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

An option that is in the types but not available in this version (validate, traits, tenancy, relations, computed, presets, policies, reference, views, functions, triggers) throws OKM1061 naming the prompt or milestone that adds it (OKM1060 stays for invalid column definitions). `.references()` takes a plain table-name string: a generic table-name argument cycles through `Register` (P12 measured the blow-up). Unknown names fail at construction (OKM1020); with emitted types the emitted file supplies the table-name union to `references`, wired when `okm build` exists (P16). Found in P12
