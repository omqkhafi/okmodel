# D226 — A hidden field in `where` or `orderBy` is OKM1120 (P81B)

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Ships variant B from D225. `column.hidden === true` refuses the field through `fail("OKM1120", …, "Call hidden({ filterable: true }).")`. `hidden({ filterable: true })` stores `ColumnModel.hidden` as `"filter"`, which `where` and `orderBy` accept. Projection, includes, aggregate field lists, and redaction still treat that value as hidden. `filters()` still refuses it (OKM1123) because `state.hidden` stays `true`. `filterable` is not on the hashed catalog, so `catalogHash` and the generated plan stay the same.
