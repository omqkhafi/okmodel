# D91 — Automatic read routing

- **Status:** accepted
- **Area:** runtime
- **Supersedes:** D67

---

Configured replicas automatically take eligible reads; `.primary()` requires the primary; `.replica()` requires a replica and fails with OKM1843 rather than reading the primary (also with no replicas configured); normal reads fall back to the primary or fail (`fallback: "error"`, OKM1844); an operation is routed once; internal read-only transactions follow the operation's routing; only user `tx()` and writes require the primary. Reason: making the developer write `.replica()` on every read defeats configuring replicas; consistency, not a default, is what protects correctness. Supersedes D67
