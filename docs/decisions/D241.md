# D241 — 0.6.0 release blockers from the second QA pass

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Column grants and revokes lowercase only the privilege keyword. Column identifiers stay the stored bytes and are quoted, including `tenantId`, `Mixed Case`, a reserved word, and a snake_case name, for `roles.reporting` and for `roles.columns` select and update. A postgres.js connection that loses its socket inside `tx()` is not written again. A later statement would schedule `socket.write` with `setImmediate` after the socket is null, and that timer throws outside the query promise. Leaving the write unsent keeps `globalThis.setImmediate` as the process installed it. The statement and the transaction reject with `unavailable`, or OKM1401 when the loss is during `COMMIT`. The process does not see an uncaught exception, and the next call uses a new connection. node-postgres maps a socket error that arrives before the next statement to the same unavailable. Bun.sql maps `connection must be a PostgresSQLConnection` the same way. `okm migrate check` lints before it replays. The replay locks `search_path` to the scratch schema, revokes `public` for that transaction, restores the ACL before a clean commit, and rolls back when the public catalog hash would change. A non-transactional statement that names `public` is refused before it is sent. Statements of different scopes on one connection run one at a time, each with its own `set_config`. `tx({ timeout })` and `batch({ timeout })` on Bun.sql and PGlite are OKM1120, reusing the per-call helper. A `signal` is not refused. OKM1550 flags a create or alter policy on a tenant table that is not the emitted expression, not only `USING (true)`. The policy guard is OKM1708. OKM1707 stays the role. The guard resolves tables with `to_regclass` on the search path. It still runs once per endpoint and generation, so a policy weakened while the process stays up is noticed on reconnect. CRLF normalisation rewrites `\r\n` inside SQL string literals. A scoped read is about 0.3 ms, a column-tenancy read about 0.06 ms, and a statement inside `tx()` about 1 ms slower. No new error kind. No catalog hash change. No public API beyond these fixes. package.json stays 0.6.0. No tag and no publish. Runtime entry 5,288 minified and 2,026 gzip. The featureless app is 90,824 / 30,166, under 90,900 / 30,170. PGlite connect is 40,297 / 14,269, under 40,450 / 14,280. postgres.js connect is 42,162 / 14,866. The postgres.js adapter adds 14,900 minified bytes over the runtime entry, under 15,093. Issue #198
