# D362 — Table partitions

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

`table({ partition })` is the only builder. `by` is `range`, `list`, or `hash`. `key` is columns. A rule (`every`, `from`, `ahead`, `keep`), a hash `count`, or an explicit `partitions` map. `children: "external"` validates the parent only. A table is managed or external. Names are `{table}_{suffix}`. `at` is required for a `timestamptz` key. Bounds are written with an explicit offset, read under `SET TIME ZONE 'UTC'`, and compared as instants. The rule is a descriptor on `schema()`. `catalog-compile.ts` compiles it. A live parent gains a child as `LIKE` (defaults, constraints, indexes, excluding identity), a validated check, then `ATTACH PARTITION`. `PARTITION OF` and plain `DETACH` are not planned on a live parent. A new parent still uses `PARTITION OF`. A parent index is `CREATE INDEX ON ONLY`, a concurrent index per child, then attach. Changing hash `count`, the key, or its type is OKM1932. A plain table converts only with no inbound foreign key and no dependent view: one transaction, `weight: "blocking"`. Rows outside the first partition are counted before that lock. `okm partitions` reads bounds, estimates, gaps, and days left. `okm partitions maintain` creates the window and applies `keep`. `then: "drop"` needs `--allow-protected`. `DETACH ... CONCURRENTLY` runs outside a transaction. A pending detach (`inhdetachpending`) is `FINALIZE`d first. `okm apply` creates the window and does not detach. `okm doctor` warns under 7 days or when `ahead` is short (OKM2130). `okm check` fails when `partman.part_config` lists a managed table (OKM2210). SQLSTATE 23514 with no constraint name is kind `check` and `reason: "no_partition"`. A query with no predicate on the key is OKM2130. A tenant predicate covers a tenant key. A statement-level `after` trigger with `referencing` is allowed on a partitioned parent. PostgreSQL 15, 17, and 19 accept it. Registry keys: `partition.range`, `partition.list`, `partition.hash`, `partition.external`, `partition.maintain`, `partition.convert`. No new `ErrorKind`. No catalog hash change for a table that has no partition. Startup added the option fields and `partitionKey` on the query model. No partition module is on the featureless graph.
