# D328 — `computed` declared once on the schema

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Approved by Ali on 2026-11-20. `schema({ computed })` declares values by table name, then value name. A read selects one with `computed: { name: true }`. The callback is the one a read takes, and `u` is typed from the schema's own tables through a type-only `~computed` member of the built schema (`DeclaredComputed`, `ComputedRow` in `src/dialects/pg/computed-types.ts`, moved down from `src/runtime/types.ts` so a dialect may import it). Two new `schema()` overloads carry the option; the existing three take `computed?: undefined`, so a call without it resolves as before. Callbacks are stored as given and never run at import or in `schema()`. `attach()` merges the declared callbacks into the read's map before `readItem`, so a declared value has the same SQL, guards, and type as an ad hoc one, shares one grouped subquery per relation, and works in `where`, `orderBy`, `one`, `.stream()`, `count`, `exists`, and `page`. Names are checked lazily in the chunk: the first read with `computed` checks each declared table is a table of the schema, the first read of a table checks its declared names. Refusals reuse OKM1120 (`true` for an undeclared name, a callback under a declared name, a declared name that is a field, a relation, or a prototype key, a declared table that is not in the schema, a value that is not a function or `true`), OKM1124, and OKM1125. Two declared names cannot clash at runtime because object keys are unique. A declaration is not a catalog object: the catalog, its hash, `generate`, `check`, `pull`, and `migrate` do not change. The `computed` option on `table()` stays OKM1061 and its message and hint say to declare it in `schema({ computed })`; `policies` keeps its refusal. No new `ErrorKind`. Known limits: a preset cannot list a declared name for free, and `okm check` does not validate declarations (that would load the compiler chunk in tooling). Size: app startup 94,665 min and 30,811 gzip against 94,645 and 30,807 (+20 and +4), under the gates 94,680 and 30,850; runtime entry 5,442 and 2,105, unchanged; postgres.js and PGlite increments unchanged; the chunk that holds the compiler grows by 1,477 min and 374 gzip. Type cost: the built-declaration ceilings do not move (instantiations unchanged, +26 types at 200 tables); the source measurement gains a constant 2,402 instantiations at every table count, and is not a ceiling.
