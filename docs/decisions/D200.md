# D200 — Gate 0.4: the protection table matches the code, and a reprinted default cast is not drift

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

`protected.policy` runs every class in spec 19.7 against a protected target and an unprotected one, through the CLI, `applyTarget`, `runTarget` (including each backfill batch), `seedProject`, and `provision`. Expected results are the table. Read-only classes (`plan`, `status`, `okm check`, `okm ext check`, drift, and the same function for `verify`, `pull`, catalog export, and `inspect`) are allowed. `okm migrate check` is OKM1850 and `--allow-protected` does not lift it. Expand, reference rows, and provision of an empty target are allowed. Contract, unclassified raw SQL, `okm push`, backfill, `okm seed`, and history repair are OKM1850 and run with `--allow-protected`. A non-empty target with no history is OKM1851, which is spec 19.6, not the protection code. `OKM_ALLOW_PROTECTED` does not exist: setting it does not lift a refusal. A target named `production` is not protected unless the flag is set. `verify`, `pull`, catalog export, and `inspect` have no command in 0.4; the function allows them, so there is nothing to bypass. History repair has no command; the function blocks it, and nothing else calls it. A contract the linter rejects is OKM1510 before the policy runs; both gates stand, and the enumeration uses an override so OKM1850 is the code under test. `okm check` and a doctor role connection call the same function for the read-only class. Drop and rollback stay refused even with `--allow-protected`; they are not rows in the 19.7 table. Finding, correctness bug, fixed: after provision, `okm check` planned `SET DEFAULT` because Postgres reprints a text default `'x'` as `'x'::text`. Postgres 15.19 and 18.6 also reprint `varchar(10)` as `'x'::character varying` (no length), `char(3)` as `'x'::bpchar`, and `timestamp(3)` / `timestamptz(3)` / `time(3)` with the precision kept on the column and omitted from the cast. `numeric(10,2)` reprints as the literal with no cast (`1.50` stays `1.50`; `1.5` stays `1.5`). Comparison strips one trailing cast when the cast's base type is the column's, with length and precision ignored for those character and time families. The stored catalog text is unchanged (D191). A cast to a different type, a different value, and a timestamp literal whose `T` Postgres reprints as a space still plan `SET DEFAULT`. Domain-check and function-body reprint stay deferred. No new API, error code, gate, cap, or ceiling. The runtime entry stays 5,288 minified and 2,026 gzip. The featureless app is 89,461 / 29,720, with 1,439 and 280 bytes left under 90,900 / 30,000.
