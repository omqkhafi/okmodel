# D303 — `okm generate` exits 1 on an error finding (Q8)

- **Status:** accepted
- **Area:** tooling, contracts
- **Supersedes:** none

---

D192 had generate write the file and print findings without refusing. CI and agents treated exit 0 as success while apply would refuse the same finding with OKM1510. Decision: generate still writes the migration and prints each finding; an error finding then exits 1 with OKM1510 and stderr that `okm migrate apply` will refuse until it is fixed. A warning-only finding stays exit 0. No new ErrorKind. No catalog hash change. No gate or ceiling moves. Issue #395
