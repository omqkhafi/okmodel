# D240 — 0.6.0 is re-cut after the QA fixes (P86R)

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

The first 0.6.0 commit is on main and was never tagged or published. npm has never had 0.6.0. P88, P88W, P89, and P89B then moved main to `0.7.0-next.4`. `bun run bump release` from that version drops the suffix and would publish 0.7.0. `bun run bump --set 0.6.0` sets 0.6.0 and promotes Unreleased. Those notes are folded into the existing `## v0.6.0 — 2026-10-11` section. Packed-tarball QA on Postgres 18 passed: `okm generate init`, `okm migrate apply`, `okm migrate check`, and `okm check` for default and snake `rlsTenancy`, `via()` with permuted table names, a materialized view with a unique index, the application and reporting roles, and `withOwner` marks; CRLF and BOM migration files; an OKM1550 hand-written disable; a live disable caught as OKM1707 on the primary and OKM1520 from `okm check`; a rolled-back savepoint and a scope switch that keep the tenant; a superuser with `rolcreaterole` false; and a reporting role that sets `app.unscoped` and reads every tenant. Upgrade from published 0.5.1 on the reference app, Postgres 15 through 18: the stored hash `c3b7c8ea6c07a5e9833fdfc7fe578ecb4d0748829a3a6f7215173ebe9b0292c2` becomes `274f95910ad8d6126fa80318a29ae6acc9e35e47b6bdd376186ecffdfe80f221`, `0004_sql_names` is eight `RENAME CONSTRAINT` statements, the workspace row stays, and check passes.
