# D89 — Vocabulary

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Target = logical deployment destination (migrations, registry); Topology = one primary plus replicas of a Target; Endpoint = one physical address with a role, owning one pool; Pool; Connection. Chains: Tenant → registry → Target → Topology → Endpoint; Operation → Router → Endpoint → Pool → Connection. Reason: "target" meant both the migration destination and the primary or replica, which would blur the design and the docs. Endpoint is internal, never public API
