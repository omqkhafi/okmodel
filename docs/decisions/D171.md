# D171 — P25 contract details settled in code

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

`archivable()` shipped in PR #104 (0.2.0-next.13) at the accepted size (D170): featureless app 87,148 / 28,938, archivable app 95,725 / 31,604 at startup and 155,844 / 50,118 with lazy chunks (reported, not gated); archive suite green on local Postgres 15, 17, 18 and on CI 15 and 18. Six details the spec had left open are now decided: (1) partial uniques are unique indexes, because Postgres cannot make a `UNIQUE` constraint partial; the primary key stays a full constraint, tenancy's extra unique on the primary-key columns becomes the same kind of partial index, and indexes written with `indexes()` are left as written. (2) `archive()` returns `{ count, archiveId }` where `count` is the targeted table only, so `expect` behaves as on `update`; cascade archives the named direct children in the same statement and does not follow those children's own cascade lists. (3) A bad cascade name is OKM1020 (unknown table, not archivable, duplicate, self, or no primary key) or OKM1021 (no foreign key, or more than one); a primary key is required when a table cascades or an archivable parent points at it. (4) `restore()` returns `{ count }`. (5) `ON CONFLICT` adds `WHERE archived_at IS NULL` only for uniques that are not the primary key. (6) A dynamic `archive` / `restore` on a non-archivable table throws OKM1052 in the trait method before any lazy import; the chunk throws the same code if reached without a model (this refines D169, which put it only in the chunk). Known limit recorded: cascade reaches direct children only, so grandchildren of an archived row stay active until their own parent is archived; a later step may add transitive cascade. Reusable for P26 to P28: `rewritePass` runs `tenancy.rewrite` first, then each trait object that has `rewrite(tables, casing, schemaTraits)`, once, schema traits then table traits; `collectHooks` gathers every object with `hook(target, ctx)` from tenancy and traits, and the client calls it for the client and again for each table. New opt-in features put compile-time work on `rewrite` and client or table methods on `hook`, and add no schema slot. Spec updated (cascade, `restore` return, partial indexes). Found in P25
