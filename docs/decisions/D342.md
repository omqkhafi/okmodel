# D342 — Typed views and materialized views use the query API

- **Status:** accepted
- **Area:** runtime
- **Supersedes:** none

---

A view is `view(name, { tables }, (q) => q.table.find, q.table.aggregate, or q.sql)`. `materializedView` is the same body. `q` has only the declared tables and views. `q.from`, `.where(sql)`, string column types, and a separate builder are removed. The body is printed by a dialect compiler (`src/dialects/pg/view/compile.ts`) with no tenant predicate and no default limit. `orderBy` without `limit` is OKM1120. A grouped view may omit `limit`. `and()` is the public conjunction next to `or`. An expression in `select` uses `.as(name)`. A flat to-one path (`"project.name"`) compiles as a left join when the target is in `tables`. Column nullability is derived from the expression or the column builder. PostgreSQL stores none of it, so a non-null column that comes back NULL is OKM1901 at read time, and `okm pull` writes `.nullable()` on every column with a note. Every view is `security_invoker` unless `{ definer: reason }`, which also sets `security_barrier`. `checkOption` is `local` or `cascaded`. A materialized view takes `refresh: "concurrently"`, `indexes` from `index()`, `using`, `with`, `tablespace`, and `populate` of `now` or `later`. `CREATE OR REPLACE` is only a column prefix (same names and types, appended columns allowed) and restates every option. A pure column rename is `ALTER VIEW RENAME COLUMN`. Anything else drops and recreates dependents in dependency order. A base column type change drops a view or matview that depends on that table. `refresh: "concurrently"` without a plain unique index (no expression, not partial) is OKM1822. A cycle in `tables` is OKM1900. `okm doctor` warns OKM1902 when a security-invoker view's base table is not selectable by the session role. Registry keys: `view.typed`, `view.materialized`, `view.security`, `view.checkOption`, `matview.refresh`, `view.dependencyOrder`, `query.exprSelect`, `query.toOnePath`. Scheduled `pg_cron` refresh, a side-by-side matview swap, and `INSTEAD OF` triggers stay recipes until a real server proves them. No `ErrorKind` is added. No gate or ceiling moves. Issue: none (PR only)
