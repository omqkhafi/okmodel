# D351 — Round 3 gaps: generated probes, storage swaps, policy entry, type grants

- **Status:** accepted
- **Area:** dialects
- **Supersedes:** none

---

Amends D347, D348, and D349. No new `ErrorKind`. OKM1927 refuses a stored/virtual swap while an index or constraint still depends on the column. OKM1928 refuses a virtual column becoming plain without `--fill`. A swap with no dependent still needs the existing type-change confirmation (OKM1915). Virtual to plain and stored to plain are `DROP EXPRESSION` (`drop-expression`, expand). Deferrability alone is `ALTER CONSTRAINT` (`alter-constraint`, expand) with no drop and no revalidation. The data probe runs before `SET EXPRESSION` on a virtual column that has a check or NOT NULL, and before `ADD COLUMN ... VIRTUAL NOT NULL` on a populated table, with the same bounded read-only count as D333, and stops with OKM1922 and "Nothing was changed." A nullable VIRTUAL column of `varchar(n)`, `numeric(p,s)`, or `smallint` is OKM1060 before SQL. Generated `sql`, including a pulled expression, is judged by `checkScratch` (OKM1848) at check and plan, with hints for `concat`, `to_tsvector`, `to_char`, `date_trunc`, `::date`, `now()`, and timestamptz casts. A BEFORE trigger `WHEN` that names a generated column is OKM1920. A virtual column whose type is an enum, domain, or composite, or whose expression calls a catalog function, is OKM1920 (0A000). Held expressions are `#` plus U+E000 plus the index, so an author expression `#0` is not a slot, and `catalogHash` still throws OKM1020 while a slot is unsealed. A tenant `setNull` or `setDefault` list may name columns other than the tenant column; the tenant column in that list, and the string form, stay OKM1060. Commit failures already go through the statement mapper: a deferred foreign key is `foreign_key` with the constraint name, and 40001 is retried by `tx({ retry })`. On PostgreSQL 17, `set-column-type`, stored `set-generated`, and adding a STORED generated column take `AccessExclusiveLock` and change `relfilenode`, so `weight: rewrite` stays. `DROP COLUMN` on a generated column drops its unique index and check, and stops with 2BP01 while a view depends. The policy compiler moves to `okmodel/policy`, loaded when a table sets `policies` or `rls`. `okmodel/session` no longer installs it. A policy created `to: "public"`, or widened to PUBLIC, is kind `policy-public` and class contract (`--allow-protected`). OKM1559 ties the class to the kind, so a per-instance class is not expressible. `grants.type` is proved on a server: USAGE on an enum, a domain, and a composite, plus USAGE and CREATE on the schema, revoke checked with `aclexplode`, and a second plan has no grant or revoke. Introspection reads those type and schema privileges for a managed role that is not the schema owner. Startup of the merged tree is the figure in D347–D349. After this change, `measureStubbedStartup` is 97,399 / 31,976 (+18 / +14). `measureEntry` of `okmodel/session` is 19,358 / 7,100 (the merged tree was 39,151 / 13,211). The runtime entry stays 5,442 / 2,105. A generated `ADD COLUMN` is not the unfilled NOT NULL check (OKM1525). The virtual probe counts it. After dotted paths (D350) the same method measures 98,443 / 32,246. This tree, including that change, measures 98,461 / 32,265 on Bun 1.4.4 (`measureStubbedStartup`, `measureRuntimeEntry` 5,442 / 2,105, `bun run type-cost`: `query-200-validate` 7,131 types and 34,145 instantiations, under 34,826). Gates move from 94,680 / 30,850 to 99,446 / 32,588 (measured plus about 1 percent). The `query-200-validate` type ceiling moves from 7,130 to 7,131. Runtime entry gates stay 6,100 / 2,250. Nothing else in those ceilings moves. The pack baseline moves from 967,247 to 1,380,551 because the new modules cross the 400 KB allowance (the merge-base tarball was already 1,271,985). Neon stubbed startup stays 42,060 against 42,030, the same number as the merge-base, and that gate is not moved. Issue: none (PR only)
