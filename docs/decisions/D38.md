# D38 — API taxonomy

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Core operations `find`/`insert`/`update`/`delete`; lifecycle operations `archive`/`restore` on archivable tables; variants are modes of those operations; `sync` is a relationship operation; `tx`/`batch` are execution primitives; guarantees are listed separately. A separate method exists only when the result shape or the logical intent differs
