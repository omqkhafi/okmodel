# D124 — Driver contract clarifications

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Every timeout (statement, transaction, batch) is kind `timeout`; `cancelled` is a separate kind, never retried, and only arises from the caller's `signal`. `batchIndex` is `number` or `null` (null when failure occurs at commit, e.g. deferred constraint; the whole batch is rolled back). `DriverConnection.batch` on a connection with an open transaction uses a savepoint and never commits the outer transaction. Release resets session state (`RESET ALL`, `pg_advisory_unlock_all()`, not `DISCARD ALL`), with a CI test that a custom setting does not survive release. Reason: M0-28, M0-29, M0-30, M0-54
