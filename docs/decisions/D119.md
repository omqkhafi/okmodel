# D119 — Roles and grants

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Roles are cluster objects: a role named in `roles` must exist and is `external` by default (checked by `okm doctor`). A declared managed role is created if missing, altered in place, and never dropped by a plan. Default privileges are keyed `(forRole, namespace, objectKind, grantee, privilege)` and emitted `ALTER DEFAULT PRIVILEGES FOR ROLE <migration role>`. Migrations run as the migration role (login, or one `SET ROLE` at session start recorded in the run report, never inside a plan); `CREATEROLE` is checked in doctor and apply preflight. Grant identity is a structured key exempt from the 63-byte rule. Reason: M0-42, M0-45, M0-48
