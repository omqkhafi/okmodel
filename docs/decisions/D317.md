# D317 — `DriverCapabilities` drops `prepared` and `describe`

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

`prepared` and `describe` left `DriverCapabilities` (#435). The flags had no reader. The type is `transactions`, `stream`, `listen`, and `cancel`. Prepared-statement mode stays a connect option (`named`, `unnamed`, or `none`). A driver that can describe a statement still exposes optional `pool.describe`. It is not a capability flag. TypeScript that reads either removed flag fails with TS2339, TS2345, or TS2353. JavaScript reads `undefined`. The connected client exposes the same frozen object. No new ErrorKind. No catalog hash change. No gate move. D300 lists only the flags that remain. Issue #435
