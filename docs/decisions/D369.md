# D369 — Handbook schema groups, the task index, and the three-step path

- **Status:** accepted
- **Area:** docs
- **Supersedes:** none

---

Schema stays one URL per page. The sidebar is seven groups: Tables and columns, Types, Keys and constraints, Security, Code in the database, Packs, and Physical layout. A group with no pages is not shown. Moved pages would redirect through the D364 resolver; this step does not rename a URL. "I want to…" is `site/lib/tasks.ts`. The page is that list rendered. The docs home and Get started both carry the three-step path (first query, schema and first migration, production check) and keep Pick a path. Get started, Concepts, and Schema use the support frontmatter. A feature page names its `POSTGRES_FEATURES` key, and the chip is the floor. The support sentence on those pages is `<SupportPhrase />` or `<Tagline />`, which render the generated sentence. The exemption list lost those pages and only shrinks. Queries, Migrations, Operate, Guides, Frameworks, and Reference stay exempt. No `okm docs`, no change feed, and no version selector. No public API change. No new `ErrorKind`. No catalog hash change. Issue: none (PR only)
