# D370 — Agent files stay short enough to read in one fetch

- **Status:** accepted
- **Area:** docs
- **Supersedes:** none

---

`llms-full.txt` is removed. There is no redirect, no shim, and no pointer. A fetch of that file was cut off mid-handbook, and a file named full that is not the whole handbook is a lie.

`llms.txt` is the index: a title, the tagline, then one link list per section. Each link is the page's markdown URL and a one-line description. The Optional section lists the split files. `llms-core` is Get started, Concepts, the query calls an agent uses first, and the "I want to…" index from `site/lib/tasks.ts`. Every other file is one docs section (`llms-schema`, `llms-queries`, and the rest). A file over 100,000 characters is split into numbered parts. The errors page is one of those parts, because the registry table is longer than the limit. The page's own `.md` URL still returns the whole page, including each code's fix.

One generator writes `llms.txt`, the split files, and the per-page markdown. Search is `GET /api/search`. An unknown URL is a 404 in HTML and in markdown, with the closest pages. No `okm docs`, no docs MCP server, and no version selector. No public API change. No new `ErrorKind`. No catalog hash change. Issue: none (PR only)
