# D96 — Atomic batch

- **Status:** accepted
- **Area:** runtime
- **Supersedes:** none

---

Atomic `batch` is part of the Driver contract, not a capability: all-or-nothing, ordered results, failing index, whole-batch timeout and cancellation, savepoint inside `tx()`, primary-required; an adapter that cannot provide it is not a driver; conformance `batch.atomic` runs on every adapter. Reason: the same API must not have weaker atomicity on one driver
