# D100 — Protection policy

- **Status:** accepted
- **Area:** dialects
- **Supersedes:** none

---

One `assertTargetPolicy` for the CLI, engine, backfill, seed, runner and provision. Allowed: read-only commands, `expand`, `reference`, `provision` on an empty target. Blocked: `contract`, unclassified steps, `push`, `backfill`, `seed`, history repair, unless `--allow-protected` (per invocation, no environment variable, selected targets only). Protection never affects runtime `connect()`
