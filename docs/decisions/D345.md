# D345 — A live plan treats a comment OKM did not record as unmanaged

- **Status:** accepted
- **Area:** tooling
- **Supersedes:** none

---

Amends the planning half of D343. `unmanagedComments` already ran inside `okm check`. Push, `okm migrate baseline`, and the `okm migrate check` replay now plan from that stripped catalog too. Push's authority is the previous migration snapshot. Baseline's authority is the head model. The replay's authority is the previous migration's catalog, empty for the first. `COMMENT … IS NULL` is still only for a comment that authority recorded. `okm migrate plan --target` and `okm generate` already plan from that snapshot, so a DBA comment never enters their `before`. Apply runs the stored SQL. Proof on PostgreSQL 17: `tests/comment-live-plan-pg.test.ts`. A DBA comment on a table, a column, and an index survives push, plan, generate, apply, check, and baseline. A comment the snapshot recorded is removed when the declaration drops it, by plan plus apply and by push before the next generate. No new `ErrorKind`. No new OKM code: OKM2107 already names the unmanaged comment. D346 removes the single-session pid loop. The pooler file at this row was `probeConcurrent` plus that loop. Measured with `bun build --target node --minify` after replacing that file's three imports with an empty module: 611 bytes of `pooler-probe.ts` (729 including a 118-byte stub). D344's 2,733 is not this file. App startup, `measureStubbedStartup` in `scripts/size.ts` with dynamic imports stubbed and `postgres` external, is 93,572 minified and 30,831 gzip before and after this change. What stays on that graph, and why it was not moved: `schema()` builds a column handle (`desc`, `nullsFirst`, `nullsLast`, `ops`, `comment`) and `compileIndexes` copies `commentText`, `nullsNotDistinct`, storage, and elements. `assertCommentText` is already only in catalog document parsing and the tooling index rules. `index()`, `storageRecord`, and `index-print.ts` are already absent from the featureless app bundle. No gate or ceiling moves. Issue: none (PR only)
