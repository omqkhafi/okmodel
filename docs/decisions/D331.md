# D331 — After-merge checks are manual, and no workflow opens issues

- **Status:** accepted
- **Area:** ci
- **Supersedes:** none

---

The After merge workflow runs by hand (`workflow_dispatch` on any ref; the Actions tab and `gh workflow run` default the ref to `main`) and always on the release candidate. The push to `main` and the 03:00 UTC schedule are gone. Release does not call this workflow. A failure is a red run. No workflow opens, comments on, reopens, or labels an issue. `gate / check` is unchanged. No public API, ErrorKind, or catalog hash change. No gate move. Issue: none filed
