# D118 — Extensions

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Extension version is unpinned by default (installed version recorded for information, ignored by drift unless pinned). The raise-version path is checked against `pg_extension_update_paths` at plan time when a server is attached; offline plans mark the step `path-unverified` and apply preflight checks before any step. A non-relocatable extension `SET SCHEMA` is refused at planning (OKM1814). Members found through `pg_depend` deptype `e` are excluded from introspection (never loaded, never diffed); objects declared in `provides` stay `external`. Reason: M0-40, M0-41, M0-47
