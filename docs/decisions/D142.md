# D142 — P16B outcomes, startup check, connect-entry budgets

- **Status:** accepted
- **Area:** runtime
- **Supersedes:** none

---

(1) Apply replays migration files; provisioning an empty target from the head snapshot (§19.6) is P53A, D123 contract gating and the rollout flags (`--class`, `--canary`, `--concurrency`, `--max-failures`) wait for the tenant registry, and D131 data steps run as plain statements until P52 batches them. (2) The stored catalog hash is read in the first dialect query through `query_to_xml`, so the statement plans even when `okm_meta` does not exist; a database with no recorded hash skips the drift check so existing databases can adopt OKModel, and P17 decides whether an explicit option makes a missing `okm_meta` OKM1520 in production. (3) Measured: app startup 76,933 / 25,444 (gate 79,240 / 26,207, cap 86,688 / 27,800), total graph 111,410 / 36,001; connect-entry gates are tied to the app startup gate and move only in the prompt that moves it, by the shared-code delta (postgres.js 39,369 / 13,671, PGlite 37,691 / 13,348); `okmodel/pg` unchanged at 151 and 79 bytes under its gate. (4) CI cold import of a connect entry includes the driver package (PGlite 24.67 ms, 1.3% under a 25 ms line), so it is reported and not gated; the 25 ms CI gate stays on the runtime entry (4.7 ms) and the 15 ms local reference applies to our own code with the driver stubbed, measured in P17. (5) The app startup budget is a per-release number: P17 sets the 0.1 budget at the measured size after a trim attempt, each release gate (P30, P44, P55, P66) proposes the next from per-feature estimates, and the D127 figure of 60 KB / 20 KB stays the runtime-entry target. (6) Refusing `push` on a target named `production` is a name heuristic, and spec §19.8 says nothing about an environment is inferred from `NODE_ENV` or a name: P17 removes the heuristic, so `push` is refused only on a target declared `protected` (and documents that production targets must be declared protected). P17 is split: P17 (hygiene, budgets, API surface freeze, unsupported-builder errors) and P17B (docs, quickstart test, recipes, compatibility table, release checklist, 0.1.0 dry run). Found in P16B
