# D333 — A data probe is a bounded read-only count

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

`generate`, `migrate plan --target`, and `apply` share one probe. Each count is `count(*)` of `select 1 … limit 10001` inside a `READ ONLY` transaction with `statement_timeout` 2s and the 3s connect bound. Exact through 10,000, `10,000 or more` above that. A timeout is "could not count in 2 s" and means the column has data. `pg_class` and `pg_stats` never decide empty. `pg_stats` may suggest a most-common value and is never preselected. Text columns also count `''` and do not change those rows. An unreachable target prints the existing note and continues. Tooling only. Issue: none filed
