# D114 — Type tests and type measurement

- **Status:** accepted
- **Area:** dialects
- **Supersedes:** none

---

Type correctness is tested with `expect-type` style assertions (`expectTypeOf`) in `*.test-d.ts` files that the normal `tsc` typecheck compiles, so a wrong type fails the existing check on TypeScript 7 without a second runner. Type cost (instantiations, check time) is measured from the compiler's own diagnostics (`tsc --extendedDiagnostics`, and a trace when needed) by a script that runs each benchmark query on the 10, 50 and 200-table fixtures and compares with recorded ceilings. `@ark/attest` needs the TypeScript compiler API, which TypeScript 7.0 does not offer; it is used only if it runs on the TypeScript 6 compatibility package in a separate job, and is dropped otherwise. Vitest is not adopted for this: its type mode calls `tsc` and parses the output and does not measure type cost. P02 records which diagnostics TypeScript 7 actually reports, and the ceilings are set from M0 evidence. Reason: type experience is the product, so it is measured and tested with tools that work on the compiler we build with
