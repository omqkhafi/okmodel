# D330 — The CLI prints through one output layer, speaks in the first person, and keeps its prefixes

- **Status:** accepted
- **Area:** tooling
- **Supersedes:** none

---

Decided with Ali on 2026-11-21. Tooling only: nothing enters the runtime entry or the app-startup graph. **One layer.** `src/tooling/cli/output.ts` prints, colors, and wraps for every `okm` command, and `failure.ts` renders every failure. **Two modes, no flag.** Pretty when stdout is a terminal, `NO_COLOR` and `CI` are unset, and `TERM` is not `dumb`; `FORCE_COLOR` (not empty, `0`, or `false`) forces pretty and wins over `NO_COLOR`, and `FORCE_COLOR=0` forces plain. Plain is everything else. Pretty adds ANSI to the severity word, the code, and a dim for `config:`, `note:`, and `Details:` lines, and nothing else: no spinner, box drawing, raw mode, arrow-key menu, or new stdin read. Plain carries the same words line for line. Prose wraps at `process.stdout.columns` or 80, on a terminal only: piped output is never wrapped, so transcripts stay greppable; SQL, findings, paths, and prefixes never wrap. **Stable prefixes.** `error <code>:`, `warning <code> `, `ok`, and `config:` hold in both modes. Streams and exit codes 0 to 5 do not change. Drift stays exit 1, and a retry is `retryable` in the JSON, not a new exit code. **`--json` is byte-identical** except the three fix texts below and `retryable` on a lock timeout. **Voice.** First person, short sentences, numbers, no exclamation marks, no jokes, no blame. An error says what happened, what was or was not done, and the next step, then `Details: okm help <code>` when the code has a page. The voice changes how a person reads a failure and not `errors[].summary`. An unexpected error prints one line and no stack; `OKM_DEBUG=1` or `--verbose` adds it. **Three fix lines** get real text: a schema file that throws on load, a database that does not exist, and a lock timeout. The lock timeout is `retryable: true`, and its fix says that running the command again is safe. **`okm help <code>`** prints the page `okm doctor <code>` prints. An unknown code says so and names the nearest one. `okm help` without a code is unchanged. No new flag, command, exit code, error code, `ErrorKind`, or public API.
