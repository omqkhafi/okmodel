# D243 — 0.7 Query depth plan

- **Status:** accepted
- **Area:** runtime
- **Supersedes:** none

---

0.7 is P90–P99. P90 reclaims bytes first: PGlite and node-postgres gzip headroom, the OKM1120 timeout message in the lazy registry, one copy of `refuseWhenLost` and `arm`, and featureless-app headroom. P91 is the postgres.js stream loop, a dedicated missing-table reason, and migrate-check cleanup. P92–P98 are the query-depth features (tools 2, 4, 5, and 7–15, `versioned`, `sortable`, `morph`, `.stream()`). Each feature loads lazily, or the step stops with the numbers and does not move a gate (D201). The order of P92 to P97 may change by measured bytes. P99 is the gate and the 0.7.0 release, with the D115 hygiene before `bun run bump release`. No source, public API, gate, or catalog hash changes in this decision. Issue #220
