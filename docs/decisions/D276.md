# D276 — Reprint warning OKM1552 and the OKM1538 no-rewrite classes (P114)

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

`okm migrate check` compares the migration catalog with the scratch schema after replay and before the OKM1547 plan. D273 still replaces a `BEGIN ATOMIC` body for that plan. A domain check or a `LANGUAGE sql` function body whose stored text differs, after trim, is warning OKM1552 on that migration's create or alter step. The warning does not fail check or apply. A reprinted domain check is sealed before the OKM1547 plan (B-37), matching a reprinted `LANGUAGE sql` body; neither is OKM1547. plpgsql is not this warning. `-- okm-allow OKM1552: reason` silences it. An empty reason, or an allow when the stored text matches, is OKM1510. The offline linter does not guess the reprint. It treats `CREATE` or `ALTER DOMAIN` and `CREATE [OR REPLACE] FUNCTION … LANGUAGE sql` as able to trigger OKM1552, so a reasoned allow is not OKM1510 before replay. OKM1538 stays a warning and fires only when the heap rewrites. It does not fire for `varchar(n)` widening, `varchar(n)` or `text` to unconstrained `varchar`, `varchar(n)` to `text`, `text` or `varchar` to unconstrained `bpchar`, a numeric precision increase at the same scale, `numeric(p,s)` to `numeric`, `integer` to `oid` and the reverse, `cidr` to `inet`, `xml` to `text`, an unconstrained domain over the old type, or any domain to its base. A `USING` expression that is not a plain cast of the column still fires. `timestamp` to `timestamptz` still fires, because a rewrite is skipped only when `TimeZone` is UTC and the linter does not connect. `varchar(n)` shrinking and `character(n)` widening do rewrite, so OKM1538 fires. OKM1524 stays quiet for a longer character length, including `character(n)`. `numeric(p,s)` to unconstrained `numeric` still fires OKM1533, because that rule still reads unconstrained numeric as precision 1000 scale 0. The column-swap safe form is not in this step. No new error kind, no public enum, no runtime-entry change
