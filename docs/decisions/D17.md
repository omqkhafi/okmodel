# D17 — Record lifecycle

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

Three operations with fixed meanings: `delete` = permanent removal of the matched records (active or archived), `archive` = reversible removal from the active dataset, `restore` = return to the active dataset. The `archivable()` trait provides the capability; how archived rows are stored is a strategy, not a different meaning
