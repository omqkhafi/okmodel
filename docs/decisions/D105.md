# D105 — Rollout control

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

With many targets: `--target`, `--class`, `--canary <n>`, `--concurrency <n>` (defaults 2 for schema-per-tenant, 8 for database-per-tenant), `--max-failures <n>` (default 3, halts a migration that breaks every tenant); `okm migrate status` shows every target's version and state (single-target status ships in M1). Reason: staged rollout and early halt are how a fleet-wide migration is made safe
