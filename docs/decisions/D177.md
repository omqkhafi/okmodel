Spec differences accepted as decisions: (1) `sum` and `avg` keep the column's value type and refuse a column that is neither a string nor a number (OKM1124); `sum` over a `text` column passes the types and fails at runtime, recorded in known limits; (2) `aggregate` returns nested objects (`row.sum.amount`), `orderBy` takes `groupBy` fields only, `limit` or `.all` is required with `groupBy`, no `having`, no `bucket`, hidden fields refused; (3) `page` requires `limit`, and its cursor is an opaque string of the order signature plus the values as Postgres wrote them (timestamps keep microseconds); (4) OKM1130 also covers a cursor that `page()` did not return; (5) `manyThrough(table, { through, from?, to? })`.
