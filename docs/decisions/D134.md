# D134 — Cold-import gate on CI

- **Status:** accepted
- **Area:** ci
- **Supersedes:** none

---

The 15 ms cold-import budget (D127) is measured on the reference machine (a developer laptop). Shared CI runners are 2–3 times slower and noisy (P12: 15.0 and 15.6 ms on a runner against 5 ms locally), so the CI gate is 25 ms on the median of five fresh imports; the local run still prints against 15 ms and any local figure above 15 ms is a finding. Size ceilings are unaffected (bytes do not vary by machine). Found in P12
