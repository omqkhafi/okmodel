# D367 — Level-triggered watch

- **Status:** accepted
- **Area:** runtime, dialects
- **Supersedes:** none

---

`watch` is a table option. `true` installs one statement-level function and three single-event triggers. `{ push: false }` installs neither. The runtime loads on the first `watch` or `until` call. A table that does not set the option has no `watch` method. NOTIFY is a hint. The handler runs at start, after a wake, after reconnect, and at least every `every`. Payloads are not row data. A live read is `find()` on the same client. Identical reads in one process share one query per wake. postgres.js, node-postgres, and PGlite can push. A failed delivery self-test, a driver without a listen connection, or an outage polls, with one warning. `push: "required"` is OKM1934. A notification queue at half full is OKM2212 on `okm doctor`. No new `ErrorKind`. No catalog hash algorithm change. Issue: none (PR only)
