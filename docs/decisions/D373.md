# D373 — One error code is one markdown page

- **Status:** accepted
- **Area:** docs
- **Supersedes:** none

---

Amends the errors-page sentence of D370. `GET /docs/reference/errors/<CODE>.md` returns only that code: the source line, the kind, the summary, the fix from `site/lib/generated/error-fixes.ts`, and links to handbook pages whose body names the code. `Accept: text/markdown` on `/docs/reference/errors/<CODE>` is the same body. An unknown code is a 404 with the closest pages, the same helper as any other missing handbook path. The Errors HTML page keeps its anchors. Its `.md` twin is an index, one line per code, under 100,000 characters. Search for a registry code points at that code's URL. `llms.txt` and the section files stay on the one generator. `llms-errors.txt` is not added, because it would repeat the index, and the old numbered reference parts are not shimmed. `okm help` and the package `docs/errors` pages are unchanged. No public API change. No new `ErrorKind`. No catalog hash change. Issue: none (PR only)
