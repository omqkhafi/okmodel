# D258 — The prototype-key guard is one shared helper; window `as` is covered (P99W)

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

D257 refuses `__proto__`, `constructor`, `toString`, and `hasOwnProperty` on `bucket()`. The guard is one shared helper, `refusePrototypeKey` in `result-name.ts`. `bucket()` and a window `as` both call it, and `bucket-group.ts` no longer keeps its own copy. The bucket message stays `bucket as <name> is a prototype key. Use another name for the result.` A window message is `<label> as <name> is a prototype key. Use another name for the result.`, where `<label>` is `rowNumber`, `rank`, `denseRank`, or `runningTotal`. The helper loads with the bucket chunk and the window chunk. The stubbed startup graph does not include it. No new error kind. No public type change. No catalog hash change. No gate move.
