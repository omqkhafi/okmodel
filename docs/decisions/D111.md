# D111 — Toolchain: TypeScript 7

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

The repository is fully TypeScript 7 (native compiler, `tsc`; nightly builds are `@typescript/native-preview`/`tsgo`): typecheck, declaration emit, editor. TypeScript 7.0 (released 2026-08-03) has no stable programmatic API until 7.1, so no OKModel tool uses the compiler API; type tests and type measurement follow D114, and the M0 spikes record TypeScript 7 results for editor-facing checks (autocomplete, `Register`, circularity). Lint and format use a tool that does not need the compiler API (Biome or oxlint, chosen in P01). TypeScript 7 defaults apply (`strict`, stable type ordering, no `baseUrl`, no legacy module resolution). Reason: one compiler for the user-facing experience, and no hidden dependency on an API that is still unstable
