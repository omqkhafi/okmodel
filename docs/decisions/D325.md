Each was measured on its own branch. Each figure is rounded up to the next 10 bytes, then 20 bytes of headroom is added, so the gate is 42,030 / 14,770. No other gate moves. A size reduction pass follows. No runtime code change. Amends D197, D201, D244, D269, and the Neon limit D324 left at 42,000. Later probes still take two consecutive failures, as D201 says. (3) `Connection terminated unexpectedly` and `Connection terminated due to connection timeout` are kind `unavailable` with no code (#693). `isConnectionFailure` still does not read error text, so a message-only error is still not lost. The kind mapper reads those two exact messages. (4) A positive Neon `connect` `timeout` on the startup check is kind `timeout` and bounds `connected` (#697).
