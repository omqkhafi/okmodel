# D151 — Supported Postgres 15 to 18, and what CI runs when

- **Status:** historical
- **Area:** ci
- **Supersedes:** none

---

The floor is Postgres 15 (13 is past end of life, 14 ends in November 2026, 15 gives `NULLS NOT DISTINCT` and `MERGE` for later); supported majors are 15, 16, 17, 18, so D150's matrix is 15 to 18. A pull request runs the suite on 15 and 18 and the tarball on 18; the full matrix runs in the release gate before publish and weekly on a schedule; `push` runs CI on `main` only so a branch with a pull request runs once, and a newer run on the same ref cancels the older. `bun run verify` runs the same suite against Docker on the developer's machine (one version, or all with a flag); CI stays the authority for a release. The code has no floor yet: `connect()` accepts a server below 15 (OKM1801 only rejects a non-PostgreSQL server; OKM1802 only fires when the schema sets `requires`), so P17G adds an explicit version floor check with its own message.
