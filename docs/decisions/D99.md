# D99 — Provisioning

- **Status:** accepted
- **Area:** product
- **Supersedes:** none

---

A new Target is provisioned from the head snapshot on an empty target (`migrate apply`, `provision()`), without replaying history; `okm migrate check` proves snapshot ≡ replayed history (OKM1521); required rows are declared with the table option `reference` (insert-if-missing, `expand`); other data DML in migrations is flagged (OKM1542); non-empty targets are refused (OKM1851). Reason: history replay would drop reference data and re-run backfills against empty tenants
