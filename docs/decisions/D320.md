# D320 — Doctor connection text

- **Status:** accepted
- **Area:** tooling
- **Supersedes:** none

---

A failed `okm doctor --production` connection is still "Could not read target `<name>`" and exit 5. When the driver message contains ECONNREFUSED, ENOTFOUND, ETIMEDOUT, ECONNRESET, EHOSTUNREACH, 28P01, 28000, 3D000, or 57P03, that token is appended in parentheses. The URL, host, user, and password stay out of the output. Amends D315. No public API, ErrorKind, or catalog hash change. No gate move. Issue: none filed
