# OKM1061

Reserved option

## What happened

The option exists in the types but this version does not implement it.

## Fix

Remove the option until the prompt or milestone named in the error adds it.

## Related

- OKM1060 Invalid column

## Examples

### bad

```ts
() => {
  archivable({ strategy: "table" });
}
```

### fixed

```ts
() => {
  archivable();
}
```
