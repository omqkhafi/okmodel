# OKM1523

Rename table

## What happened

A statement renames a table. Existing queries still use the old name.

## Fix

Create the new table, backfill, and switch readers before dropping the old name.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.
