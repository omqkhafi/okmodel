# OKM1024

Table file not in schema

## What happened

A table file is not passed to schema().

## Fix

Add the file's table to the schema() call that okm check reads.

## Related

- OKM1020 Unknown table
- OKM1021 Foreign key target
- OKM1022 Foreign key type
- OKM1023 Duplicate name
- OKM1026 Dependency cycle
- OKM1027 Unreadable catalog

## Examples

### bad

```ts
() => checkProject(tableProject(!0))
```

### fixed

```ts
() => checkProject(tableProject(!1))
```
