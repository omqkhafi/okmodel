# OKM1200

Validation failed

## What happened

A write or a standalone check failed a validation rule. issues lists each path and message key.

## Fix

Fix the fields named in issues. Each issue message is a key, not display text.

## Related

- OKM1201 Validation not imported

## Examples

### bad

```ts
async () => {
  const tasks = table("tasks", { title: t.text().validate([v.min(1, "short")]) }), app = schema({ tables: [tasks], validation: !0 });
  await stand(app.model.tasks, tasks, !0, "insert", { title: "" }, "valid");
}
```

### fixed

```ts
async () => {
  const tasks = table("tasks", { title: t.text().validate([v.min(1, "short")]) }), app = schema({ tables: [tasks], validation: !0 });
  await stand(app.model.tasks, tasks, !0, "insert", { title: "ok" }, "valid");
}
```
