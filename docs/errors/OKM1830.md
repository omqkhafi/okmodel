# OKM1830

Lock outside transaction

## What happened

find was called with a row lock outside tx().

## Fix

Take the lock inside tx(). Advisory locks are transaction-scoped too.

## Related

None.

## Examples

### bad

```ts
async () => {
  await notesClient().notes.find({ limit: 1, lock: "update" });
}
```

### fixed

```ts
async () => {
  await notesClient().notes.find({ limit: 1 });
}
```
