# OKM1899

Ledger name taken

## What happened

A migration ledger name already belongs to another table.

## Fix

Rename that table, or drop it. okm keeps its migration ledger under this name.

## Examples

### bad

```ts
() => {
  refuseForeignLedger("appns", "okm_steps", "r", ["id"]);
}
```

### fixed

```ts
() => {
  refuseForeignLedger("appns", "okm_steps", "r", ledgerRequiredColumns("okm_steps") ?? []);
}
```
