# OKM1605

Stale typed SQL entry

## What happened

A typed SQL lock entry is no longer called from the source.

## Fix

okm raw sync writes the lock and the generated types. Commit both.

## Related

- OKM1601 Stale typed SQL
- OKM1602 Bad typed SQL
- OKM1603 Raw SQL is not static
- OKM1604 Typed SQL is not locked

## Examples

### bad

```ts
() => staleLockCodes(["kept"], ["kept", "stale"])
```

### fixed

```ts
() => staleLockCodes(["kept"], ["kept"])
```
