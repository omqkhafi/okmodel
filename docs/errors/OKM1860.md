# OKM1860

Feature refused

## What happened

The configured dialect refuses a feature this schema uses.

## Fix

Use the portable alternative named in the error. The message names the dialect, the feature, and the first version that would support it when one exists.

## Related

- OKM1862 Different driver
- OKM1863 Init decision
- OKM1864 User-modified file
- OKM1865 Unsupported project
- OKM1866 Plan hash mismatch
- OKM1867 Tenancy mode

## Examples

### bad

```ts
() => {
  assertSupported(["schema.core"], {
    "schema.core": {
      support: "refused",
      proof: "proof",
      alternative: "Use a table this dialect can create.",
      code: "OKM1860"
    }
  }, "sqlite");
}
```

### fixed

```ts
() => {
  assertSupported(["schema.core"], {
    "schema.core": { support: "native", proof: "proof" }
  }, "sqlite");
}
```
