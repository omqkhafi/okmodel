# OKM1701

Tenant context missing

## What happened

A tenant table was used on a client that has no tenant context.

## Fix

Open the client with for() before reading or writing that table.

## Escape hatches

Each hatch requires a human-written reason.

- unscoped()

## escape

A human-written reason is required.

unscoped()

## Examples

### bad

```ts
async () => {
  await connect(pool, {
    schema: schema({
      tenancy: columnTenancy({ key: "tenantId", type: "uuid" }),
      tables: [table("notes", { id: t.text().primaryKey(), title: t.text() })]
    })
  }).table("notes").find({ limit: 1 });
}
```

### fixed

```ts
async () => {
  await connect(pool, {
    schema: schema({
      tenancy: columnTenancy({ key: "tenantId", type: "uuid" }),
      tables: [table("notes", { id: t.text().primaryKey(), title: t.text() })]
    })
  }).for({ tenantId: TENANT }).notes.find({ limit: 1 });
}
```
