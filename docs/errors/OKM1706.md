# OKM1706

Tenant index

## What happened

An index on a tenant table does not lead with the tenant key, and the schema is not prefixing indexes. Prefixing is on unless indexes: false or tenantIndexes: false. index().global("reason") is the opt-out that does not raise this.

## Fix

Put the tenant key first, or leave indexes on so the schema adds it. index().global("reason") opts one index out.

## Examples

### bad

```ts
() => {
  schema({
    tenancy: columnTenancy({ key: "tenantId", type: "uuid", indexes: !1 }),
    tables: [
      table("notes", { id: t.identity(), title: t.text() }, { indexes: (columns) => [index(columns.title)] })
    ]
  });
}
```

### fixed

```ts
() => {
  schema({
    tenancy: columnTenancy({ key: "tenantId", type: "uuid", indexes: !1 }),
    tables: [table("notes", { id: t.identity(), title: t.text() })]
  });
}
```
