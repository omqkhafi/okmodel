# OKM1896

Reprint needs a writable session

## What happened

A check, picklist, domain check, generated column, or btree index expression is reprinted on a temporary table. This connection is read-only, or the role cannot create temporary tables.

## Fix

Point the command at a writable primary. The role needs TEMP on the database. It does not need CREATE on the schema. Parallel runs use a random temporary name.

## Examples

### bad

```ts
() => {
  const error = readOnlyReprint(Error("cannot execute CREATE TABLE in a read-only transaction"));
  if (error !== void 0)
    throw error;
}
```

### fixed

```ts
() => {
  readOnlyReprint(Error('column "status" does not exist'));
}
```
