# OKM1557

Step cannot be made re-runnable

## What happened

A committed step has no built-in probe and no declared probe, so a failure cannot tell whether the change is already in place.

## Fix

Declare one read-only SELECT that returns a single boolean, true when the change is already in place, or keep the step inside the migration transaction.
