# OKM1897

Pull left objects behind

## What happened

okm push would drop a column or constraint that okm pull listed under not pulled yet.

## Fix

Those columns and constraints stay in the database. Pull did not write them, so push does not drop them.

## Examples

### bad

```ts
() => {
  refuseUnpulledDrops(["notes.note"]);
}
```

### fixed

```ts
() => {
  refuseUnpulledDrops([]);
}
```
