# OKM1531

Validating check

## What happened

A statement adds or validates a check against rows already stored.

## Fix

Add the check NOT VALID, repair the rows, then validate it.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

-- okm-allow
