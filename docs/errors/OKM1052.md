# OKM1052

Not archivable

## What happened

archive or restore was called on a table that is not archivable.

## Fix

Call it only on an archivable table. The methods are absent from the types of other tables.

## Related

- OKM1051 Archive foreign key

## Examples

### bad

```ts
async () => {
  await connect(pool, {
    schema: schema({
      tables: [
        table("notes", { id: t.identity(), title: t.text() }),
        table("files", { id: t.identity() }, { traits: [archivable()] })
      ]
    })
  }).notes.archive({ where: { id: "1" } });
}
```

### fixed

```ts
async () => {
  await connect(pool, {
    schema: schema({
      tables: [table("files", { id: t.identity() }, { traits: [archivable()] })]
    })
  }).files.archive({ where: { id: "1" } });
}
```
