# OKM1553

Step needs a human

## What happened

A committed step failed and the probe cannot tell whether it is applied. Apply leaves it until someone decides.

## Fix

Inspect the database. Record the step as applied when the change is in place, or mark it for another attempt. okm migrate resolve takes the step id from okm migrate status.

## Examples

### bad

```ts
() => resumeCommittedStep(committedNote(), failedMarker(committedNote().sqlHash), unknownEngine(), {
  retries: 0,
  wrap: (error) => error
})
```

### fixed

```ts
() => resumeCommittedStep(committedNote(), failedMarker(committedNote().sqlHash), appliedEngine(), {
  retries: 0,
  wrap: (error) => error
})
```
