# OKM1021

Foreign key target

## What happened

A foreign key is missing its target table or column, or the target is ambiguous.

## Fix

Name the referenced table and columns. The error lists the columns that exist on the target.

## Related

- OKM1020 Unknown table
- OKM1022 Foreign key type
- OKM1023 Duplicate name
- OKM1024 Table file not in schema
- OKM1025 Multiple Register
- OKM1026 Dependency cycle
- OKM1027 Unreadable catalog

## Examples

### bad

```ts
() => {
  schema({
    tables: [
      table("users", { email: t.text() }),
      table("tasks", { ownerId: t.uuid().references("users") })
    ]
  });
}
```

### fixed

```ts
() => {
  schema({
    tables: [
      table("users", { id: t.uuid().primaryKey(), email: t.text() }),
      table("tasks", { ownerId: t.uuid().references("users") })
    ]
  });
}
```
