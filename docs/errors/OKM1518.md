# OKM1518

Drop materialized view

## What happened

A statement drops a materialized view and the rows it stores.

## Fix

Stop reading the view in an expand migration, then drop it.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

-- okm-allow

## Examples

### bad

```ts
() => {
  const stored = materializedView("titles", {
    columns: [{ name: "title", type: "text" }],
    query: "select title from tasks"
  });
  return schemaCodes(schema({ tables: [tasks()], views: [stored] }), schema({ tables: [tasks()] }));
}
```

### fixed

```ts
() => {
  const stored = materializedView("titles", {
    columns: [{ name: "title", type: "text" }],
    query: "select title from tasks"
  });
  return schemaCodes(schema({ tables: [] }), schema({ tables: [tasks()], views: [stored] }));
}
```
