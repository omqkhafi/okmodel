# OKM1528

Unique constraint

## What happened

A statement adds a unique or primary-key constraint on a table that already has rows.

## Fix

Deduplicate the rows first.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.
