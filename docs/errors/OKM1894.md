# OKM1894

Testing object exists

## What happened

testing() found a table or extension that already exists in the database.

## Fix

Use an empty database, or pass migrate: false when the schema is already applied.

## Related

- OKM1890 Observer keys
- OKM1891 Ambiguous config
- OKM1892 Workspace choice
- OKM1893 Shared migrations
- OKM1895 Usage

## Examples

### bad

```ts
() => {
  testingObjectConflict("table", "notes");
}
```

### fixed

```ts
() => {
  return "migrate omitted on an empty database";
}
```
