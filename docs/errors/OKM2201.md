# OKM2201

Production timeouts

## What happened

okm doctor --production found a lock_timeout or statement_timeout of 0. Apply or a statement can then wait without limit. The finding is a warning: nothing is refused.

## Fix

Set timeouts.lock in the config, and ALTER ROLE <app role> SET statement_timeout to the limit you want.

## Related

- OKM2200 Observer buffer overflow
- OKM2202 Target not protected
- OKM2203 Pooler target
- OKM2204 Production check failed

## Examples

### bad

```ts
() => timeoutFindings({ ...plain, timeouts: { lock: 0 } }, 0, 0).flatMap((item) => item.code ?? [])
```

### fixed

```ts
() => timeoutFindings({ ...plain, timeouts: { lock: 5000 } }, 5000, 30000).flatMap((item) => item.code ?? [])
```
