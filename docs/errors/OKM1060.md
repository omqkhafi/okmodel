# OKM1060

Invalid column

## What happened

A column definition has a bad length, precision, scale, array rank, interval qualifier, or an empty or repeated picklist or enum.

## Fix

Use a value the error lists as accepted.

## Related

- OKM1061 Reserved option

## Examples

### bad

```ts
() => {
  t.domain("pos", t.integer(), "");
}
```

### fixed

```ts
() => {
  t.domain("pos", t.integer(), "((VALUE > 0))");
}
```
