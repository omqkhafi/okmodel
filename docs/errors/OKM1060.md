# OKM1060

Invalid column

## What happened

A column definition has a bad length, precision, scale, array rank, interval qualifier, or an empty or repeated picklist or enum. .unique() on a gin or gist index is this code too: Postgres builds unique indexes with btree only. A schema() casing other than snake or camel is this code too.

## Fix

Use a value the error lists as accepted. Remove .unique() from a gin or gist index, or use btree. Pass snake or camel for casing, or leave it out.

## Related

- OKM1061 Reserved option

## Examples

### bad

```ts
() => {
  t.domain("pos", t.integer(), "");
}
```

### fixed

```ts
() => {
  t.domain("pos", t.integer(), "((VALUE > 0))");
}
```
