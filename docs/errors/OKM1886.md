# OKM1886

Agent path refused

## What happened

An agent file path is not on the list okm may write, resolves outside the project directory, is not a regular file, or could not be written.

## Fix

Keep the agent files as regular files inside the project directory.

## Related

- OKM1881 Agent files drifted
- OKM1882 Agent markers damaged
- OKM1883 Agent block duplicated
- OKM1884 Agent files need a yes

## Examples

### bad

```ts
() => {
  agentPath(tmpdir(), ".claude/settings.json", new Set(["AGENTS.md"]));
}
```

### fixed

```ts
() => {
  agentPath(tmpdir(), "AGENTS.md", new Set(["AGENTS.md"]));
}
```
