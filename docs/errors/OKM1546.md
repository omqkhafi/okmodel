# OKM1546

Backfill key

## What happened

A backfill step targets a table that has no primary key.

## Fix

Add a primary key. A backfill walks that key and does not scan the table.

## Examples

### bad

```ts
() => {
  primaryKeyColumns([schema({ tables: [table("notes", { title: t.text() })] }).catalog], "notes");
}
```

### fixed

```ts
() => {
  primaryKeyColumns([notesCatalog], "notes");
}
```
