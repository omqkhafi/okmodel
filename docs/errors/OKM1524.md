# OKM1524

Column type change

## What happened

A statement changes a column type. Existing readers and writers may not accept the new type.

## Fix

Add a new column, backfill, and switch readers before dropping the old one.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.
