# OKM1539

Timestamp without time zone

## What happened

A column is timestamp without time zone. The instant depends on the session time zone.

## Fix

Use timestamptz.

## Related

- OKM1530 Ambiguous rename

## Examples

### bad

```ts
() => lintCatalog(schema({ tables: [table("tasks", { id: t.identity(), at: t.timestamp() })] }).catalog).map((item) => item.code)
```

### fixed

```ts
() => lintCatalog(schema({ tables: [table("tasks", { id: t.identity(), at: t.timestamptz() })] }).catalog).map((item) => item.code)
```
