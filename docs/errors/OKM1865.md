# OKM1865

Unsupported project

## What happened

The directory has no package.json, cannot be written, or a path leaves it.

## Fix

Use a package directory that can be written, and keep paths inside it.

## Related

- OKM1860 Feature refused
- OKM1862 Different driver

## Examples

### bad

```ts
() => {
  refuseUnsupported("okm init needs a package.json in the project directory.");
}
```

### fixed

```ts
() => {
  refuseUnsupported(void 0);
}
```
