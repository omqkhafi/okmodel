# OKM1604

Typed SQL is not locked

## What happened

A raw statement in the source is not in the typed SQL lock.

## Fix

okm raw sync writes the lock and the generated types. Commit both.

## Related

- OKM1601 Stale typed SQL
- OKM1602 Bad typed SQL
- OKM1603 Raw SQL is not static
- OKM1605 Stale typed SQL entry

## Examples

### bad

```ts
() => {
  assertLocked(["statement"], []);
}
```

### fixed

```ts
() => {
  assertLocked(["statement"], ["statement"]);
}
```
