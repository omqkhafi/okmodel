# OKM1891

Ambiguous config

## What happened

Two okmodel.config.ts files are the same distance from the working directory.

## Fix

Pass --config <path> to the config this command should load.

## Related

- OKM1890 Observer keys
- OKM1892 Workspace choice
- OKM1893 Shared migrations
- OKM1894 Testing object exists
- OKM1895 Usage
- OKM1896 Reprint needs a writable session

## Examples

### bad

```ts
() => {
  refuseAmbiguousConfigs(["packages/api/okmodel.config.ts", "packages/web/okmodel.config.ts"]);
}
```

### fixed

```ts
() => {
  refuseAmbiguousConfigs(["packages/api/okmodel.config.ts"]);
}
```
