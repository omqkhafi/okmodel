# OKM1891

Workspace choice

## What happened

okm init needs a workspace and this invocation is not interactive.

## Fix

Pass --workspace <name>, --all-workspaces, or --shared.

## Related

- OKM1890 Ambiguous config
- OKM1892 Shared migrations

## Examples

### bad

```ts
() => {
  refuseWorkspaceChoice(["@acme/api (packages/api)", "@acme/web (packages/web)"]);
}
```

### fixed

```ts
() => {
  refuseWorkspaceChoice(["@acme/api (packages/api)"]);
}
```
