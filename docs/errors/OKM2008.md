# OKM2008

Wide fan-out

## What happened

An include multiplies the parent limit by nested limits past 10,000 rows.

## Fix

Lower the parent limit or an include limit.

## Rule

`wide-fan-out`

## Default

Level `warn`. Severity `high`. Phase `dev-runtime`. Evidence `static`.

## Safe alternatives

- Lower the parent limit or an include limit.

## page

Lower the parent limit or an include limit.

## Escape hatches

Each hatch requires a human-written reason.

- ignore

## escape

A human-written reason is required.

ignore

## Related

- OKM2004 Deep offset
- OKM2005 Unordered limit
- OKM2007 Large value list

## Examples

### bad

```ts
async () => {
  await warnDb("wide-fan-out").notes.find({
    limit: 101,
    orderBy: { id: "asc" },
    include: { comments: { limit: 100 } }
  });
}
```

### fixed

```ts
async () => {
  await warnDb("wide-fan-out").notes.find({
    limit: 100,
    orderBy: { id: "asc" },
    include: { comments: { limit: 100 } }
  });
}
```
