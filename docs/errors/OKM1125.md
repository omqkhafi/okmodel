# OKM1125

Bad SQL fragment

## What happened

A composed fragment is empty, unbalanced, includes a backslash, or interpolates a value it cannot bind. A select fragment that is not a number is the same code.

## Fix

Interpolate a string, number, boolean, null, ident(name), fragment.column, or another fragment. Keep parentheses and quotes balanced. Pass a value that needs a backslash as an interpolation. A select fragment is a numeric expression named with as().

## Examples

### bad

```ts
async () => {

  class Row {
    id = "";
  }
  await raw(notesClient().notes, Row, "read", fragment`select ${fragment.column} from notes`);
}
```

### fixed

```ts
async () => {

  class Row {
    id = "";
  }
  await raw(notesClient().notes, Row, "read", fragment`select ${ident("id")} from notes`);
}
```
