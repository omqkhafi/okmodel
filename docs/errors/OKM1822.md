# OKM1822

Concurrent refresh

## What happened

REFRESH CONCURRENTLY was declared without a unique index on the materialized view.

## Fix

Add a unique index, or refresh without CONCURRENTLY.

## Related

- OKM1820 View tenancy
- OKM1821 Replace needs recreate
- OKM1823 Security definer path
- OKM1824 Function dependencies
- OKM1825 Missing privilege

## Examples

### bad

```ts
() => {
  materializedView("titles", {
    columns: [{ name: "title", type: "text" }],
    query: "select title from notes",
    refresh: "concurrently"
  });
}
```

### fixed

```ts
() => {
  materializedView("titles", {
    columns: [{ name: "title", type: "text" }],
    query: "select title from notes"
  });
}
```
