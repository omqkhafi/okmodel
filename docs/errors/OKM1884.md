# OKM1884

Agent files need a yes

## What happened

The plan changes an existing file, and okm cannot ask: there is no terminal, or --json is on, and --yes was not passed.

## Fix

Read the plan with the dry flag, then pass --yes. Or answer the prompt on a terminal.
