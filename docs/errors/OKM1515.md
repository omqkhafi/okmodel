# OKM1515

Drop function

## What happened

A statement drops a function that queries or triggers may still call.

## Fix

Remove the callers in an expand migration, then drop the function.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

-- okm-allow

## Examples

### bad

```ts
() => {
  const answer = fn("answer", { returns: "integer", language: "sql", body: "select 1" });
  return schemaCodes(schema({ tables: [tasks()], functions: [answer] }), schema({ tables: [tasks()] }));
}
```

### fixed

```ts
() => {
  const answer = fn("answer", { returns: "integer", language: "sql", body: "select 1" });
  return schemaCodes(schema({ tables: [] }), schema({ tables: [tasks()], functions: [answer] }));
}
```
