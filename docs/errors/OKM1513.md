# OKM1513

Drop enum

## What happened

A statement drops an enum that columns or code may still depend on.

## Fix

Move every column off the enum first.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

-- okm-allow
