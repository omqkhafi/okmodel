# OKM2007

Large value list

## What happened

A value list longer than 500 elements sends one parameter per element.

## Fix

Filter with = any(array) so the list is one parameter.

## Rule

`large-in-list`

## Default

Level `warn`. Severity `medium`. Phase `dev-runtime`. Evidence `static`.

## Safe alternatives

- Filter with = any(array) so the list is one parameter.

## page

Filter with = any(array) so the list is one parameter.

## Escape hatches

Each hatch requires a human-written reason.

- ignore

## escape

A human-written reason is required.

ignore

## Examples

### bad

```ts
async () => {
  const values = Array.from({ length: 501 }, (_, index) => String(index));
  await warnDb("large-in-list").notes.find({
    where: { title: inList(values) },
    limit: 1,
    orderBy: { id: "asc" }
  });
}
```

### fixed

```ts
async () => {
  await warnDb("large-in-list").notes.find({
    where: { title: inList(["1"]) },
    limit: 1,
    orderBy: { id: "asc" }
  });
}
```
