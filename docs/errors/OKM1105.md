# OKM1105

Include without limit

## What happened

A to-many include has no limit.

## Fix

Pass a limit on the include.

## Escape hatches

Each hatch requires a human-written reason.

- all()

## escape

A human-written reason is required.

all()

## Related

- OKM1101 Find without limit
- OKM1102 Unfiltered write
- OKM1104 Upsert target

## Examples

### bad

```ts
async () => {
  const comments = table("comments", {
    id: t.identity(),
    noteId: t.bigint().references("notes"),
    body: t.text()
  }), notes = table("notes", { id: t.identity(), title: t.text() }, { relations: { comments: many("comments", "noteId") } });
  await connect(pool, { schema: schema({ tables: [notes, comments] }) }).notes.find({ limit: 1, include: { comments: !0 } });
}
```

### fixed

```ts
async () => {
  const comments = table("comments", {
    id: t.identity(),
    noteId: t.bigint().references("notes"),
    body: t.text()
  }), notes = table("notes", { id: t.identity(), title: t.text() }, { relations: { comments: many("comments", "noteId") } });
  await connect(pool, { schema: schema({ tables: [notes, comments] }) }).notes.find({ limit: 1, include: { comments: { limit: 1 } } });
}
```
