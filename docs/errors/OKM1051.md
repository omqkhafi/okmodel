# OKM1051

Archive foreign key

## What happened

A foreign key into a table-strategy archivable table uses CASCADE, SET NULL, or SET DEFAULT and is not listed in cascade.

## Fix

List the child table, the foreign key, and its action in cascade, or use RESTRICT or NO ACTION.
