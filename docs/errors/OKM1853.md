# OKM1853

Target not named

## What happened

Several targets are configured and the command was not given --target.

## Fix

Pass --target <name>. The command does not guess.

## Examples

### bad

```ts
() => {
  selectTarget({
    schema: "schema.ts",
    targets: {
      a: "postgres://localhost:5432/app",
      b: "postgres://localhost:5432/other"
    }
  }, void 0);
}
```

### fixed

```ts
() => {
  selectTarget({
    schema: "schema.ts",
    targets: {
      a: "postgres://localhost:5432/app",
      b: "postgres://localhost:5432/other"
    }
  }, "a");
}
```
