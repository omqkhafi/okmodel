# OKM1541

Picklist removal

## What happened

A picklist or enum value was removed and the replacement was not given.

## Fix

Pass --replace <table>.<column>.<old>=<new>, or =null on a nullable column. The replacement must be in the new list.

### bad

```ts

  parseReplace("nope");
}
```

### fixed

```ts
() => {
  parseReplace("notes.title.old=new");
}
```
