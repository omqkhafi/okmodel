# OKM1882

Agent markers damaged

## What happened

A file has a BEGIN OKMODEL or END OKMODEL line that is malformed, unpaired, or out of order, so okm cannot tell which text it owns. It does not repair markers.

## Fix

Restore one BEGIN OKMODEL line and one END OKMODEL line, or delete both and the text between them, then repeat the command.

## Examples

### bad

```ts
() => {
  findBlock(`<!-- BEGIN OKMODEL v0.10.0 -->
OKModel notes
`, "AGENTS.md");
}
```

### fixed

```ts
() => {
  findBlock(`<!-- BEGIN OKMODEL v0.10.0 -->
OKModel notes
<!-- END OKMODEL -->
`, "AGENTS.md");
}
```
