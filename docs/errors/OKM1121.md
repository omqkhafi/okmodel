# OKM1121

Object as value

## What happened

An empty or() branch is OKM1121. or() takes one array: or([a, b]). A plain object was passed where a value is required.

## Fix

Give every or() branch a predicate. Pass an array: or([a, b]). Wrap a json value with eq.

## Examples

### bad

```ts
async () => {
  await notesClient().notes.find({ limit: 1, where: or([{}]) });
}
```

### fixed

```ts
async () => {
  await notesClient().notes.find({ limit: 1, where: or([{ title: "a" }, { title: "b" }]) });
}
```
