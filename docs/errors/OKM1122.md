# OKM1122

Bad identifier

## What happened

An identifier is empty, too long, contains NUL or another control character, or is an unquoted reserved word.

## Fix

Use a shorter name without control characters. Quote is not accepted here. The error names the rule that failed.

## Examples

### bad

```ts

  ident("");
}
```

### fixed

```ts

  ident("title");
}
```
