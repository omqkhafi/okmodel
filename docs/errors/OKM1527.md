# OKM1527

Shrink length

## What happened

A statement shortens a character length. Values longer than the new limit no longer fit.

## Fix

Shorten the stored values first, or keep the old length.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.
