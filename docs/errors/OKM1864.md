# OKM1864

User-modified file

## What happened

A file init recorded was edited, so init leaves it unchanged.

## Fix

Keep the file, or pass the force-file flag with that path to replace it.

## Related

- OKM1860 Feature refused
- OKM1862 Different driver
- OKM1863 Init decision
- OKM1865 Unsupported project
- OKM1866 Plan hash mismatch
- OKM1867 Tenancy mode

## Examples

### bad

```ts
() => {
  refuseUserModified(["db/schema.ts"]);
}
```

### fixed

```ts
() => {
  refuseUserModified([]);
}
```
