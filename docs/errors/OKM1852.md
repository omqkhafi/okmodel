# OKM1852

Protection mismatch

## What happened

Targets that resolve to the same database disagree about protection, or tenants of one schema-per-tenant database do.

## Fix

Give those targets the same protection flag. okm check and okm doctor both report this.

## Examples

### bad

```ts
() => {
  assertTargetAlias(listTargets({
    schema: "schema.ts",
    targets: {
      a: { url: "postgres://localhost:5432/app", protected: !0 },
      b: { url: "postgres://localhost:5432/app" }
    }
  }));
}
```

### fixed

```ts
() => {
  assertTargetAlias(listTargets({
    schema: "schema.ts",
    targets: {
      a: { url: "postgres://localhost:5432/app", protected: !0 },
      b: { url: "postgres://localhost:5432/app", protected: !0 }

```
