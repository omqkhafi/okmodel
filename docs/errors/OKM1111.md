# OKM1111

Missing capability

## What happened

The call needs a driver capability this driver does not have.

## Fix

Use a driver that declares the capability, or drop the call. The error names the flag.

## Related

- OKM1110 Engine version

## Examples

### bad

```ts
async () => {
  await notesClient().tx(async () => {
    return;
  });
}
```

### fixed

```ts
async () => {
  await notesClient().notes.find({ limit: 1 });
}
```
