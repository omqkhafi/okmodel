# OKM1881

Agent files drifted

## What happened

okm agents status found an agent file that is not current: the AGENTS.md block, the CLAUDE.md import, or a skill file is stale, missing, or modified.

## Fix

Use okm agents update to rewrite the block and any unmodified skill, or okm init --agents when the files were never written.

## Related

- OKM1882 Agent markers damaged
- OKM1883 Agent block duplicated
- OKM1884 Agent files need a yes
- OKM1885 Agent content refused
- OKM1886 Agent path refused
- OKM1887 Agent file changed
- OKM1888 Init record damaged

## Examples

### bad

```ts
() => {
  refuseDrift([{ path: "AGENTS.md", state: "stale" }]);
}
```

### fixed

```ts
() => {
  refuseDrift([{ path: "AGENTS.md", state: "current" }]);
}
```
