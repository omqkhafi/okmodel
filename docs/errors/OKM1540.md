# OKM1540

varchar length

## What happened

A column is varchar(n). text stores the same values without a length limit in the type.

## Fix

Use text, and check the length in the application when one is required.

## Examples

### bad

```ts
() => lintCatalog(schema({ tables: [table("tasks", { id: t.identity(), name: t.varchar(20) })] }).catalog).map((item) => item.code)
```

### fixed

```ts
() => lintCatalog(schema({ tables: [table("tasks", { id: t.identity(), name: t.text() })] }).catalog).map((item) => item.code)
```
