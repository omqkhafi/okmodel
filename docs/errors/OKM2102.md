# OKM2102

Table without a primary key

## What happened

A table with no primary key has no stable row identity for updates and deletes.

## Fix

Declare a primary key on the table.

## Rule

`table-without-primary-key`

## Default

Level `warn`. Severity `medium`. Phase `check`. Evidence `static`.

## Safe alternatives

- Declare a primary key on the table.

## page

Declare a primary key on the table.

## Escape hatches

Each hatch requires a human-written reason.

- ignore

## escape

A human-written reason is required.

ignore

## Related

## Examples

### bad

```ts
() => adviceCodes(schema({ tables: [table("events", { name: t.text() })] }))
```

### fixed

```ts
() => adviceCodes(schema({ tables: [table("events", { id: t.identity(), name: t.text() })] }))
```
