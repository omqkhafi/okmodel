# OKM1012

Trait field conflict

## What happened

A trait added a field that the table already declares.

## Fix

Rename the table field or drop the trait that introduces it. The error names both.

## Related

None.

## Examples

### bad

```ts
() => schema({
  traits: [timestamps()],
  tables: [table("notes", { id: t.text().primaryKey(), createdAt: t.text() })]
}).catalog
```

### fixed

```ts
() => schema({
  traits: [timestamps()],
  tables: [table("notes", { id: t.text().primaryKey() })]
}).catalog
```
