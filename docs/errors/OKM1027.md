# OKM1027

Unreadable catalog

## What happened

The catalog document is malformed or uses a version this build cannot read.

## Fix

Regenerate the catalog with this version of okmodel. Do not hand-edit the document.

- OKM1020 Unknown table

### bad

```ts
() => {
  parseCatalog("{");

```

### fixed

```ts
() => {
  parseCatalog(serializeCatalog(empty));
}
```
