# OKM1887

Agent file changed

## What happened

A file changed after the plan was made and before it was replaced, so okm stopped. Files already written stay.

## Fix

Repeat the command so the diff matches the file.

- OKM1881 Agent files drifted

### bad

```ts
() => {
  refuseChanged("AGENTS.md", `edited by hand
`, `as planned
`);
}
```

### fixed

```ts
() => {
  refuseChanged("AGENTS.md", `as planned
`, `as planned
```
