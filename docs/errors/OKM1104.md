# OKM1104

Upsert target

## What happened

onConflict names columns that are not a unique constraint.

## Fix

Set on to the columns of a unique constraint or the primary key.

## Related

- OKM1101 Find without limit
- OKM1102 Unfiltered write
- OKM1105 Include without limit

## Examples

### bad

```ts
async () => {
  await notesClient().notes.insert({ title: "a" }, {
    onConflict: { on: "title", return: !0 }
  });
}
```

### fixed

```ts
async () => {
  await notesClient().notes.insert({ title: "a" }, {
    onConflict: { on: "id", return: !0 }
  });
}
```
