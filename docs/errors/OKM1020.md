# OKM1020

Unknown table

## What happened

A table, dependency, or catalog object is missing or does not match its identity.

## Fix

Use a name that is in the schema. The error lists the accepted names and a nearest-name hint when one is close.

## Related

- OKM1021 Foreign key target
- OKM1022 Foreign key type
- OKM1023 Duplicate name
- OKM1024 Table file not in schema
- OKM1026 Dependency cycle
- OKM1027 Unreadable catalog

## Examples

### bad

```ts
() => {
  return schema({ tables: [table("notes", { email: t.citext() })] }).catalog;
}
```

### fixed

```ts
() => {
  return schema({
    tables: [table("notes", { email: t.text() })]
  }).catalog;
}
```
