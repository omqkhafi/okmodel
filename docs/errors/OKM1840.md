# OKM1840

Replica not allowed

## What happened

A replica route was used on an operation that requires the primary, or inside tx().

## Fix

Use the primary. Writes, batch, locks, and tx() never go to a replica.

## Related

- OKM1841 External object differs
- OKM1842 Cross-database foreign key
- OKM1843 No eligible replica
- OKM1844 Fallback refused

- OKM1846 Acquire timeout

## Examples

### bad

```ts
async () => {
  await notesClient().notes.find({ limit: 1, lock: "update", route: "replica" });
}
```

### fixed

```ts
async () => {
  await notesClient().notes.find({ limit: 1 });
}
```
