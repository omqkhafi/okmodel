# OKM1820

View tenancy

## What happened

A view over tenant tables does not expose the tenant key and is not marked global.

## Fix

Expose the tenant key so the predicate can be applied, or declare global(reason).

## Related

- OKM1821 Replace needs recreate
- OKM1822 Concurrent refresh
- OKM1823 Security definer path
- OKM1824 Function dependencies
- OKM1825 Missing privilege

## Examples

### bad

```ts
() => {
  schema({
    casing: "snake",
    tenancy: columnTenancy({ key: "tenantId", type: "uuid" }),
    tables: [table("tasks", { id: t.identity(), title: t.text() })],
    views: [
      view("titles", {
        columns: [{ name: "title", type: "text" }],
        query: "select title from tasks"
      })
    ]
  });
}
```

### fixed

```ts
() => {
  schema({
    casing: "snake",
    tenancy: columnTenancy({ key: "tenantId", type: "uuid" }),
    tables: [table("tasks", { id: t.identity(), title: t.text() })],
    views: [
      view("titles", {
        columns: [
          { name: "tenant_id", type: "uuid" },
          { name: "title", type: "text" }
        ],
        query: "select tenant_id, title from tasks"
      })
    ]
  });
}
```
