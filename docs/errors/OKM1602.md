# OKM1602

Bad typed SQL

## What happened

A raw statement is not one select or one write the checker can classify, or two result columns share a name.

## Fix

Start the statement with select, insert, update, or delete. with is a write when it contains insert, update, delete, or merge. Give result columns distinct names.

## Related

- OKM1601 Stale typed SQL
- OKM1603 Raw SQL is not static
- OKM1604 Typed SQL is not locked
- OKM1605 Stale typed SQL entry

## Examples

### bad

```ts
async () => {

  class Row {
    id = "";
  }
  const db = connect(pool, {
    schema: schema({
      tenancy: columnTenancy({ key: "tenantId", type: "uuid" }),
      tables: [notesTable()]
    })
  });
  await raw(db.for({ tenantId: TENANT }).notes, Row, "read", "select 1");
}
```

### fixed

```ts
async () => {

  class Row {
    id = "";
  }
  await raw(notesClient().notes, Row, "read", fragment`select ${ident("id")} from notes`);
}
```
