# OKM1602

Bad typed SQL

## What happened

A raw statement is missing its class, is not one select or one write, or the result class has no column initializers.

## Fix

Pass "read" or "write", a fragment`...`, and a class with an initializer on every column. Identifiers are ident(name).

## Related

- OKM1601 Stale typed SQL

## Examples

### bad

```ts
async () => {

  class Row {
    id = "";
  }
  const db = connect(pool, {
    schema: schema({
      tenancy: columnTenancy({ key: "tenantId", type: "uuid" }),
      tables: [notesTable()]
    })
  });
  await raw(db.for({ tenantId: TENANT }).notes, Row, "read", "select 1");
}
```

### fixed

```ts
async () => {

  class Row {
    id = "";
  }
  await raw(notesClient().notes, Row, "read", fragment`select ${ident("id")} from notes`);
}
```
