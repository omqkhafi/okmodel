# OKM1705

Global references tenant

## What happened

A global table references a tenant table.

## Fix

Drop the reference, or make the referencing table a tenant table.

## Related

- OKM1701 Tenant context missing
- OKM1702 Unverifiable tenant SQL
- OKM1704 Tenant key change
- OKM1706 Tenant index
- OKM1707 RLS role
- OKM1708 RLS policy

## Examples

### bad

```ts
() => {
  schema({
    tenancy: columnTenancy({ key: "tenantId", type: "uuid" }),
    tables: [
      table("tasks", { id: t.text().primaryKey() }),
      table("audit", { id: t.text().primaryKey(), taskId: t.uuid().references("tasks") }, { tenancy: global("audit log") })
    ]
  });
}
```

### fixed

```ts
() => {
  schema({
    tenancy: columnTenancy({ key: "tenantId", type: "uuid" }),
    tables: [
      table("tasks", { id: t.text().primaryKey() }),
      table("audit", { id: t.text().primaryKey() }, { tenancy: global("audit log") })
    ]
  });
}
```
