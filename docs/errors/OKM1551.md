# OKM1551

Transaction control in a step

## What happened

A step contains COMMIT, ROLLBACK, or other transaction control, including inside a DO body. A function or procedure body is not this.

## Fix

Remove the transaction control. okm migrate check replays one transaction and rolls it back.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

-- okm-allow
