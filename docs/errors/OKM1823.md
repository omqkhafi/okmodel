# OKM1823

Security definer path

## What happened

A SECURITY DEFINER function has no search_path.

## Fix

Set search_path on the function to the schemas it is allowed to see.

## Related

- OKM1820 View tenancy
- OKM1821 Replace needs recreate
- OKM1822 Concurrent refresh
- OKM1824 Function dependencies
- OKM1825 Missing privilege

## Examples

### bad

```ts
() => {
  fn("read", { returns: "integer", language: "sql", security: "definer", body: "select 1" });
}
```

### fixed

```ts
() => {
  fn("read", {
    returns: "integer",
    language: "sql",
    security: "definer",
    body: "select 1",
    searchPath: "public"
  });
}
```
