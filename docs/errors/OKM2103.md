# OKM2103

Filter or sort column without an index

## What happened

Callers can filter or sort by this column and no index starts with it, so each read scans the table.

## Fix

Add an index that starts with the column, or remove the column from the allowlist or preset.

## Rule

`unindexed-filter-column`

## Default

Level `warn`. Severity `medium`. Phase `check`. Evidence `static`.

## Safe alternatives

- Add an index that starts with the column.

- Remove the column from the filters allowlist, the sort list, or the preset.

## page

## Examples

### bad

```ts
() => adviceCodes(schema({
  tables: [
    table("tasks", { id: t.identity(), status: t.text() }, { presets: { pending: (q) => q.where({ status: "pending" }) } })
  ]
}))
```

### fixed

```ts
() => adviceCodes(schema({
  tables: [
    table("tasks", { id: t.identity(), status: t.text() }, {
      presets: { pending: (q) => q.where({ status: "pending" }) },
      indexes: (columns) => [index(columns.status)]
    })
  ]
}))
```
