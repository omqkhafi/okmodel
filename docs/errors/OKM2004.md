# OKM2004

Deep offset

## What happened

An offset past 1,000 rows makes the database scan every skipped row.

## Fix

Use page() with a cursor.

## Rule

`deep-offset`

## Default

Level `warn`. Severity `medium`. Phase `dev-runtime`. Evidence `static`.

## Safe alternatives

- Use page() with a cursor.

## page

Use page() with a cursor.

## Escape hatches

Each hatch requires a human-written reason.

- ignore

## escape

A human-written reason is required.

ignore

## Examples

### bad

```ts
async () => {
  await warnDb("deep-offset").notes.find({ limit: 1, offset: 1001, orderBy: { id: "asc" } });
}
```

### fixed

```ts
async () => {
  await warnDb("deep-offset").notes.page({ limit: 1 });
}
```
