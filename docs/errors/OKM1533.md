# OKM1533

Narrowing type

## What happened

A statement narrows a numeric or integer type. Values outside the new range no longer fit.

## Fix

Rewrite the values into the new range first.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

-- okm-allow

## Examples

### bad

```ts
() => diffCodes(table("tasks", { id: t.identity(), n: t.bigint() }), table("tasks", { id: t.identity(), n: t.integer() }))
```

### fixed

```ts
() => diffCodes(table("tasks", { id: t.identity(), n: t.integer() }), table("tasks", { id: t.identity(), n: t.bigint() }))
```
