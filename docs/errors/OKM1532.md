# OKM1532

Validating foreign key

## What happened

A statement adds or validates a foreign key against rows already stored.

## Fix

Add the foreign key NOT VALID, repair the rows, then validate it.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.
