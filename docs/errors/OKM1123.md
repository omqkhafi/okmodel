# OKM1123

Hidden field allowlist

## What happened

A hidden field was added to a filter or sort allowlist.

## Fix

Remove the hidden field from the allowlist. Hidden fields stay out of caller filters and sorts.

## Related

- OKM1120 Unknown field
- OKM1121 Object as value
- OKM1122 Bad identifier
- OKM1124 Operator mismatch
- OKM1125 Bad SQL fragment
- OKM1126 Parameter limit
- OKM1127 Relation order with distinct
- OKM1128 Relation order in aggregate

## Examples

### bad

```ts
() => {
  table("notes", { id: t.identity(), secret: t.text().hidden() }).filters({
    allow: { secret: ["eq"] }
  });
}
```

### fixed

```ts
() => {
  table("notes", { id: t.identity(), title: t.text(), secret: t.text().hidden() }).filters({
    allow: { title: ["eq"] }
  });
}
```
