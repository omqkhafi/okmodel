# OKM1704

Tenant key change

## What happened

An update tried to change the tenant key.

## Fix

Remove the tenant key from the update. Moving a row between tenants is not an update.

## Related

- OKM1701 Tenant context missing
- OKM1702 Unverifiable tenant SQL

- OKM1709 Session setting

## Examples

### bad

```ts
async () => {
  await connect(pool, {
    schema: schema({
      tenancy: columnTenancy({ key: "tenantId", type: "uuid" }),
      tables: [table("notes", { id: t.text().primaryKey(), title: t.text() })]
    })
  }).for({ tenantId: TENANT }).notes.update({
    where: { id: "a" },
    set: { tenantId: TENANT }
  });
}
```

### fixed

```ts
async () => {
  await connect(pool, {
    schema: schema({
      tenancy: columnTenancy({ key: "tenantId", type: "uuid" }),
      tables: [table("notes", { id: t.text().primaryKey(), title: t.text() })]
    })
  }).for({ tenantId: TENANT }).notes.update({ where: { id: "a" }, set: { title: "n" } });
}
```
