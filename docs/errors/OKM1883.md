# OKM1883

Agent block duplicated

## What happened

A file has more than one OKMODEL block, so okm cannot tell which one it owns. It does not merge blocks.

## Fix

Keep one OKMODEL block and delete the others, then repeat the command.

## Examples

### bad

```ts
() => {
  findBlock(`<!-- BEGIN OKMODEL v0.10.0 -->
a
<!-- END OKMODEL -->
<!-- BEGIN OKMODEL v0.10.0 -->
b
<!-- END OKMODEL -->
`, "AGENTS.md");
}
```

### fixed

```ts
() => {
  findBlock(`<!-- BEGIN OKMODEL v0.10.0 -->
a
<!-- END OKMODEL -->
`, "AGENTS.md");
}
```
