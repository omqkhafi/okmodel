# OKM1210

Codec rejected a value

## What happened

A codec refused a value: not numeric text, not a valid temporal value, or the wrong shape.

## Fix

Pass a value the error lists as accepted. A missing Temporal global tells you to assign one to globalThis.Temporal.

## Related

None.

## Examples

### bad

```ts
() => {
  decodeBigintNumber("nope");
}
```

### fixed

```ts
() => {
  decodeBigintNumber("1");
}
```
