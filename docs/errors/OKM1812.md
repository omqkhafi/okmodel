# OKM1812

Feature version

## What happened

A feature needs a newer PostgreSQL than minPostgres, or an extension version the server does not have. The message names the feature and the version.

## Fix

Raise minPostgres, or avoid the feature. uuidv7() needs PostgreSQL 18 or higher. minPostgres: 18. An extension pin names the version to install. Core features are never gated on an extension.

## Related

- OKM1810 Extension not declared
- OKM1811 Extension unavailable
- OKM1813 Extension defined twice
- OKM1814 Extension change refused

## Examples

### bad

```ts
() => {
  schema({
    requires: { postgres: ">=17" },
    tables: [table("users", { id: id({ default: "uuidv7" }), name: text() })]
  });
}
```

### fixed

```ts
() => {
  schema({
    requires: { postgres: ">=18" },
    tables: [table("users", { id: id({ default: "uuidv7" }), name: text() })]
  });
}
```
