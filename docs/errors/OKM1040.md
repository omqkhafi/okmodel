# OKM1040

Preset name collision

## What happened

A preset uses the name of a client method or a reserved name, or a table and its traits (or two traits) define the same preset.

## Fix

Rename the preset. The error names both sources when two define it. okm upgrade renames a preset when a later release claims its name.

## Related

None.

## Examples

### bad

```ts
() => {
  trait("bad", { fields: {}, presets: { find: (query) => query } });
}
```

### fixed

```ts
() => {
  trait("labeled", { fields: { label: t.text() } });
}
```
