# OKM2300

Weak override reason

## What happened

A migration override gives a reason that is shorter than 12 characters, only stop-list words, or only the code repeated. This is a warning: nothing is refused.

## Fix

Write one sentence that says why this step is safe here: what was checked, and who agreed.

## Related

None.

## Examples

### bad

```ts
() => weakAllows(`-- okm-allow OKM1511: ok
drop table notes`)
```

### fixed

```ts
() => weakAllows(`-- okm-allow OKM1511: notes moved to the archive schema and the export was verified
drop table notes`)
```
