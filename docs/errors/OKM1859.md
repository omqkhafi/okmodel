# OKM1859

Store fingerprint

## What happened

A store fingerprint blocks this state-changing command when there is no terminal.

## Fix

Open a terminal for this invocation. A terminal is friction, not proof of a human.

## Examples

### bad

```ts
() => {
  assertTargetPolicy({ name: "default", protected: !0, protection: "store" }, "push", !0, {
    tty: !1
  });
}
```

### fixed

```ts
() => {
  assertTargetPolicy({ name: "default", protected: !0, protection: "store" }, "push", !0, {
    tty: !0
  });
}
```
