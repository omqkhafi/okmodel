# OKM1810

Extension not declared

## What happened

An extension builder was used but the extension is not declared on the schema.

## Fix

Declare the extension next to the schema that uses it.

## Related

- OKM1811 Extension unavailable
- OKM1812 Feature version
- OKM1813 Extension defined twice
- OKM1814 Extension change refused

## Examples

### bad

```ts
() => schema({
  tables: [table("people", { email: t.citext() })],
  extensions: [extension("pg_trgm")]
}).catalog
```

### fixed

```ts
() => schema({
  tables: [table("people", { email: t.citext() })],
  extensions: [extension("citext")]
}).catalog
```
