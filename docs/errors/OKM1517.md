# OKM1517

Drop extension

## What happened

A statement drops an extension. A dependent still in the catalog is refused before this finding.

## Fix

Confirm nothing outside the catalog uses the extension.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

-- okm-allow
