# OKM1401

Outcome unknown

## What happened

A commit or batch was sent and its result never arrived, so the write may or may not have happened.

## Fix

Check whether the write landed, using an idempotency key, before retrying. This error is never retried automatically.

## Related

None.

## Examples

### bad

```ts
() => {
  throw mapPostgresError(outcomeUnknown());
}
```

### fixed

```ts
() => {
  throw mapPostgresError(new OkmError("invalid", "not a lost commit"));
}
```
