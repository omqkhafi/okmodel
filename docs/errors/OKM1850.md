# OKM1850

Protected target

## What happened

The operation is blocked on a protected target.

## Fix

Use a read-only command or an expand migration.

## Escape hatches

Each hatch requires a human-written reason.

- --allow-protected

## escape

A human-written reason is required.

--allow-protected
