# OKM1888

Init record damaged

## What happened

.okm/init.json is not a JSON object, so okm cannot record the hashes of the agent files it writes.

## Fix

Restore .okm/init.json from version control, or delete it and use okm init again.

```ts
}
```

### fixed

```ts
  withAgentsRecord("{}", { choice: "yes" });
```
