# OKM1514

Drop domain

## What happened

A statement drops a domain that columns or code may still depend on.

## Fix

Move every column off the domain first.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

-- okm-allow

## Examples

### bad

```ts
() => diffCodes(table("tasks", {
  id: t.identity(),
  name: t.domain("label", t.text(), "((length(VALUE) > 0))")
}), table("tasks", { id: t.identity() }))
```

### fixed

```ts
() => diffCodes(table("tasks", { id: t.identity() }), table("tasks", {
  id: t.identity(),
  name: t.domain("label", t.text(), "((length(VALUE) > 0))")
}))
```
