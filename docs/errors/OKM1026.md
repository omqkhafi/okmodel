# OKM1026

Dependency cycle

## What happened

The catalog dependency graph contains a cycle, so objects cannot be ordered.

## Fix

Break the cycle. The error is raised while ordering the catalog.

## Related

- OKM1020 Unknown table
- OKM1021 Foreign key target
- OKM1022 Foreign key type
- OKM1023 Duplicate name
- OKM1024 Table file not in schema
- OKM1025 Multiple Register
- OKM1027 Unreadable catalog

## Examples

### bad

```ts
() => {
  const provenance = { origin: "file", name: "db/tasks.ts" }, ns = staticNamespace("public"), parent = { namespace: ns, name: "tasks" }, left = { kind: "column", parent, name: "alpha" }, right = { kind: "column", parent, name: "beta" };
  buildCatalog([
    catalogTable({ namespace: ns, name: "tasks", provenance }),
    catalogColumn({
      parent,
      name: "alpha",
      dataType: "text",
      nullable: !1,
      provenance,
      dependencies: [right]
    }),
    catalogColumn({
      parent,
      name: "beta",
      dataType: "text",
      nullable: !1,
      provenance,
      dependencies: [left]
    })
  ]);
}
```

### fixed

```ts
() => {
  const provenance = { origin: "file", name: "db/tasks.ts" }, ns = staticNamespace("public"), parent = { namespace: ns, name: "tasks" };
  buildCatalog([
    catalogTable({ namespace: ns, name: "tasks", provenance }),
    catalogColumn({ parent, name: "id", dataType: "text", nullable: !1, provenance })
  ]);
}
```
