# OKM1030

Validation in two places

## What happened

A field is validated both on the column and somewhere else.

## Fix

Keep one validation for the field. The error names the field.

## Related

None.

## Examples

### bad

```ts
() => {
  assertValidation(schema({
    tables: [
      table("tasks", { title: text().validate([v.min(1, "title_required")]) }, { validate: { title: [v.min(1, "title_required")] }, validation: !0 })
    ]
  }));
}
```

### fixed

```ts
() => {
  assertValidation(schema({
    tables: [table("tasks", { title: text().validate([v.min(1, "title_required")]) })]
  }));
}
```
