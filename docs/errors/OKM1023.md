# OKM1023

Duplicate name

## What happened

Two catalog objects share an identity, two tables emit the same type name, or two fields of one table spell the same SQL name after casing.

## Fix

Rename one of them, or name one with sqlName. Table names and emitted type names must be unique in the schema.

## Related

- OKM1020 Unknown table
- OKM1021 Foreign key target
- OKM1022 Foreign key type

## Examples

### bad

```ts
() => {
  return schema({
    tables: [
      table("notes", { id: t.text().primaryKey() }),
      table("notes", { id: t.text().primaryKey() })
    ]
  }).catalog;
}
```

### fixed

```ts
() => {
  return schema({
    tables: [
      table("notes", { id: t.text().primaryKey() }),
      table("tasks", { id: t.text().primaryKey() })
    ]
  }).catalog;
}
```
