# OKM1023

Duplicate name

## What happened

Two catalog objects share an identity, or two tables emit the same type name.

## Fix

Rename one of them. Table names and emitted type names must be unique in the schema.

## Related

- OKM1020 Unknown table
- OKM1021 Foreign key target
- OKM1022 Foreign key type
- OKM1024 Table file not in schema
- OKM1025 Multiple Register
- OKM1026 Dependency cycle
- OKM1027 Unreadable catalog

## Examples

### bad

```ts
() => {
  return schema({
    tables: [
      table("notes", { id: t.text().primaryKey() }),
      table("notes", { id: t.text().primaryKey() })
    ]
  }).catalog;
}
```

### fixed

```ts
() => {
  return schema({
    tables: [
      table("notes", { id: t.text().primaryKey() }),
      table("tasks", { id: t.text().primaryKey() })
    ]
  }).catalog;
}
```
