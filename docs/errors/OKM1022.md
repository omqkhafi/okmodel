# OKM1022

Foreign key type

## What happened

A foreign key column and the column it references have different types.

## Fix

Give both columns the same type. The error names the type that is accepted.

## Related

- OKM1020 Unknown table
- OKM1021 Foreign key target
- OKM1023 Duplicate name
- OKM1024 Table file not in schema
- OKM1026 Dependency cycle
- OKM1027 Unreadable catalog

## Examples

### bad

```ts
() => {
  schema({
    tables: [
      table("users", { id: t.id() }),
      table("tasks", { ownerId: t.integer().references("users") })
    ]
  });
}
```

### fixed

```ts
() => {
  schema({
    tables: [
      table("users", { id: t.id() }),
      table("tasks", { ownerId: t.uuid().references("users") })
    ]
  });
}
```
