# OKM1854

Pooler session

## What happened

Two statements on the same connection saw different backend pids. A transaction-mode pooler is in the way.

## Fix

Use a direct connection.

## Escape hatches

Each hatch requires a human-written reason.

- --allow-pooler

## escape

A human-written reason is required.

--allow-pooler
