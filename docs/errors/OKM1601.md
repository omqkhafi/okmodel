# OKM1601

Stale typed SQL

## What happened

A typed raw statement is missing from the lock, the lock does not parse, or its signature no longer matches the database.

## Fix

Rerun okm raw sync and commit .okm/raw.lock.json and .okm/raw.d.ts.

## Related

- OKM1602 Bad typed SQL
- OKM1603 Raw SQL is not static
- OKM1604 Typed SQL is not locked
- OKM1605 Stale typed SQL entry

## Examples

### bad

```ts
() => {
  assertSignature({
    sql: "select 1",
    kind: "read",
    params: [],
    columns: [{ name: "n", pgType: "integer", nullable: !0 }]
  }, {
    sql: "select 1",
    kind: "read",
    params: [],
    columns: [{ name: "n", pgType: "text", nullable: !0 }]
  });
}
```

### fixed

```ts
() => {
  const column = { name: "n", pgType: "integer", nullable: !0 };
  assertSignature({ sql: "select 1", kind: "read", params: [], columns: [column] }, { sql: "select 1", kind: "read", params: [], columns: [column] });
}
```
