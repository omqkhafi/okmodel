# OKM1603

Raw SQL is not static

## What happened

raw SQL must be a static string.

## Fix

Pass a string literal or a template literal with no substitutions as the SQL.

## Related

- OKM1601 Stale typed SQL
- OKM1602 Bad typed SQL
- OKM1604 Typed SQL is not locked
- OKM1605 Stale typed SQL entry

## Examples

### bad

```ts
() => {
  discoverRawCalls([
    { path: "src/app.ts", text: `import { raw } from "okmodel/pg";
raw(db, sql, []);
` }
  ]);
}
```

### fixed

```ts
() => {
  discoverRawCalls([
    { path: "src/app.ts", text: `import { raw } from "okmodel/pg";
raw(db, "select 1", []);
` }
  ]);
}
```
