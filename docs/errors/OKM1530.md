# OKM1530

Ambiguous rename

## What happened

A rename could match more than one object.

## Fix

Declare the rename explicitly so the plan has one pairing.

## Examples

### bad

```ts
() => {
  planMigration({
    before: schema({ tables: [table("tasks", { id: t.identity(), title: t.text() })] }).catalog,
    after: schema({ tables: [table("tasks", { id: t.identity(), name: t.text() })] }).catalog,
    name: "example"
  });
}
```

### fixed

```ts
() => {
  const after = schema({
    tables: [table("tasks", { id: t.identity(), name: t.text().renamedFrom("title") })]
  });
  planMigration({
    before: schema({ tables: [table("tasks", { id: t.identity(), title: t.text() })] }).catalog,
    after: after.catalog,
    renames: schemaDeclarations(after).renames,
    name: "example"
  });
}
```
