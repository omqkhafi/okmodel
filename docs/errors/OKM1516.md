# OKM1516

Drop view

## What happened

A statement drops a view that queries may still read.

## Fix

Stop reading the view in an expand migration, then drop it.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

-- okm-allow

## Examples

### bad

```ts
() => {
  const listed = view("titles", {
    columns: [{ name: "title", type: "text" }],
    query: "select title from tasks"
  });
  return schemaCodes(schema({ tables: [tasks()], views: [listed] }), schema({ tables: [tasks()] }));
}
```

### fixed

```ts
() => {
  const listed = view("titles", {
    columns: [{ name: "title", type: "text" }],
    query: "select title from tasks"
  });
  return schemaCodes(schema({ tables: [] }), schema({ tables: [tasks()], views: [listed] }));
}
```
