# OKM1898

Data loss

## What happened

okm push would drop columns and tables that hold rows.

## Fix

Keep the column or table, or pass --allow-data-loss when those rows can go.

## Examples

### bad

```ts
() => {
  refuseDataLoss(["notes.extra"]);
}
```

### fixed

```ts
() => {
  refuseDataLoss([]);
}
```
