# OKM1542

Data statement

## What happened

A migration contains a data statement outside backfill(), or a DO or CALL whose body is not analysed.

## Fix

Move insert, update, delete, merge, and truncate into backfill(). DO and CALL are refused because the body is not analysed.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.
