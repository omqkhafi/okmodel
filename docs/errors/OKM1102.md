# OKM1102

Unfiltered write

## What happened

A write with no effective predicate, including undefined values, is OKM1102.

## Fix

Pass a predicate. An undefined-only where is the same as an empty filter.

## Escape hatches

Each hatch requires a human-written reason.

- all()

## escape

A human-written reason is required.

all()

## Related

- OKM1101 Find without limit
- OKM1104 Upsert target
- OKM1105 Include without limit

## Examples

### bad

```ts
async () => {
  await notesClient().notes.delete({});
}
```

### fixed

```ts
async () => {
  await notesClient().notes.delete({ where: { id: "1" } });
}
```
