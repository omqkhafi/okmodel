# OKM1824

Function dependencies

## What happened

A plpgsql function has no dependsOn. Postgres does not record dependencies inside the body.

## Fix

List dependsOn. LANGUAGE sql with BEGIN ATOMIC is inferred and does not need the list.

## Related

- OKM1820 View tenancy
- OKM1821 Replace needs recreate
- OKM1822 Concurrent refresh

## Examples

### bad

```ts
() => {
  fn("touch", { returns: "trigger", language: "plpgsql", body: "begin return new; end" });
}
```

### fixed

```ts
() => {
  fn("touch", {
    returns: "trigger",
    language: "plpgsql",
    body: "begin return new; end",
    dependsOn: []
  });
}
```
