# OKM1893

Shared migrations

## What happened

Two packages use the same migrations directory.

## Fix

Give each package its own migrations directory.

## Related

- OKM1890 Observer keys
- OKM1891 Ambiguous config
- OKM1892 Workspace choice
- OKM1894 Testing object exists
- OKM1895 Usage
- OKM1896 Reprint needs a writable session
- OKM1897 Pull left objects behind
- OKM1898 Data loss

## Examples

### bad

```ts
() => {
  refuseSharedMigrations(["packages/api", "packages/web"], "packages/web/migrations");
}
```

### fixed

```ts
() => {
  refuseSharedMigrations(["packages/api"], "packages/api/migrations");
}
```
