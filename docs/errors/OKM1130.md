# OKM1130

Cursor order

## What happened

A cursor was reused with a different orderBy than the one that created it, or is not a cursor page() returned.

## Fix

Request the next page with the same orderBy and the exact next value the previous page returned. The cursor encodes that order.

## Related

None.

## Examples

### bad

```ts
async () => {
  await notesClient().notes.page({ limit: 1, after: "not-a-cursor" });
}
```

### fixed

```ts
async () => {
  await notesClient().notes.page({ limit: 1 });
}
```
