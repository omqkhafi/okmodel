# OKM1544

json column

## What happened

A column is json. jsonb is available and stores the same documents in binary.

## Fix

Use jsonb.

- OKM1540 varchar length

## Examples

### bad

```ts
() => lintCatalog(schema({ tables: [table("tasks", { id: t.identity(), body: t.json() })] }).catalog).map((item) => item.code)
```

### fixed

```ts
() => lintCatalog(schema({ tables: [table("tasks", { id: t.identity(), body: t.jsonb() })] }).catalog).map((item) => item.code)
```
