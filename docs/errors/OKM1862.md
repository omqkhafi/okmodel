# OKM1862

Different driver

## What happened

A driver package is already installed and the driver flag names a different one.

## Fix

Drop the driver flag, or remove the installed driver package before choosing another.

## Related

- OKM1860 Feature refused
- OKM1863 Init decision
- OKM1864 User-modified file
- OKM1865 Unsupported project
- OKM1866 Plan hash mismatch
- OKM1867 Tenancy mode

## Examples

### bad

```ts
() => {
  refuseDifferentDriver("postgresjs", "pg");
}
```

### fixed

```ts
() => {
  refuseDifferentDriver("pg", "pg");
}
```
