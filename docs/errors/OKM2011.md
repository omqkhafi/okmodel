# OKM2011

Default limit reached

## What happened

A read that used a default limit from connect returned exactly that many rows, so more rows may exist.

## Fix

Pass a limit that fits the call, or use page() with a cursor.

## Rule

`default-limit-reached`

## Default

Level `warn`. Severity `medium`. Phase `dev-runtime`. Evidence `observed`.

## Safe alternatives

- Pass a limit that fits the call.

- Use page() with a cursor.

- Call .all(reason) when every row is needed.

## page

Pass a limit that fits the call.

Use page() with a cursor.

Call .all(reason) when every row is needed.

## Escape hatches

Each hatch requires a human-written reason.

- ignore

## escape

A human-written reason is required.

ignore

## Related

None.

## Examples

### bad

```ts
async () => {
  await limitedDb().notes.find({ orderBy: { id: "asc" } });
}
```

### fixed

```ts
async () => {
  await limitedDb().notes.find({ orderBy: { id: "asc" }, limit: 1 });
}
```
