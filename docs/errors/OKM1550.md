# OKM1550

Row-level security weakened

## What happened

A statement disables row-level security, drops or widens a policy, grants BYPASSRLS, or changes the owner of a tenant table.

## Fix

Remove the statement.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

-- okm-allow
