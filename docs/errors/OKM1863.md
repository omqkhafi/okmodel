# OKM1863

Init decision

## What happened

okm init needs a choice and this invocation is not interactive.

## Fix

Pass the flag named in the message. The flags are --driver, --tenancy, and --install.

## Related

- OKM1860 Feature refused
- OKM1862 Different driver
- OKM1864 User-modified file
- OKM1865 Unsupported project
- OKM1866 Plan hash mismatch
- OKM1867 Tenancy mode

## Examples

### bad

```ts
() => {
  refuseMissingDecision(["--driver"]);
}
```

### fixed

```ts
() => {
  refuseMissingDecision([]);
}
```
