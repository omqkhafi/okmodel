# OKM1511

Drop table

## What happened

A statement drops a table. The rows and anything that reads them are gone.

## Fix

Stop reading the table in an expand migration, then drop it in a later contract.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

-- okm-allow
