# OKM1534

Index locks

## What happened

A statement creates an index on an existing table without CONCURRENTLY.

## Fix

Create the index with CREATE INDEX CONCURRENTLY, outside a transaction. The planner does this on an existing table.

## Examples

### bad

```ts
() => hand("create index notes_title on notes (title)", notesCatalog)
```

### fixed

```ts
() => hand("create index concurrently notes_title on notes (title)", notesCatalog)
```
