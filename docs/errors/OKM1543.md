# OKM1543

serial column

## What happened

A column uses serial or a nextval default. Identity is the form this repo generates.

## Fix

Use an identity column generated always.

## Examples

### bad

```ts
() => lintCatalog(withColumn(schema({ tables: [tasks()] }).catalog, "title", {
  dataType: "int4",
  defaultExpression: "nextval('tasks_title_seq'::regclass)"
})).map((item) => item.code)
```

### fixed

```ts
() => lintCatalog(schema({ tables: [tasks()] }).catalog).map((item) => item.code)
```
