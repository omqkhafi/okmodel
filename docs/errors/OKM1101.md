# OKM1101

Find without limit

## What happened

find was called without a limit.

## Fix

Pass a limit.

## Safe alternatives

- Use page() with a cursor.

## page

Use page() with a cursor.

## Escape hatches

Each hatch requires a human-written reason.

- all()

## escape

A human-written reason is required.

all()

## Related

- OKM1102 Unfiltered write
- OKM1104 Upsert target
- OKM1105 Include without limit

## Examples

### bad

```ts
async () => notesClient().notes.find({})
```

### fixed

```ts
async () => notesClient().notes.find({ limit: 1 })
```
