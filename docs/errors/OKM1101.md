# OKM1101

Find without limit

## What happened

find was called without a limit, or a limit is above limits.max. connect({ limits }) can set a default for find, page, and groupBy.

## Fix

Pass a limit. A limit must not be above limits.max.

## Safe alternatives

- Use page() with a cursor.

- Set limits.find in connect for a default row count.

## page

Use page() with a cursor.

Set limits.find in connect for a default row count.

## Escape hatches

Each hatch requires a human-written reason.

- all()

## escape

A human-written reason is required.

all()

## Examples

### bad

```ts
async () => notesClient().notes.find({})
```

### fixed

```ts
async () => notesClient().notes.find({ limit: 1 })
```
