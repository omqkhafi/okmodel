# OKM1556

Step statement changed

## What happened

The migration file's statement changed after the committed step started.

## Fix

Restore the statement that started, or replace the file only after the database matches it.

## Related

- OKM1550 Row-level security weakened
- OKM1551 Transaction control in a step

## Examples

### bad

```ts
() => resumeCommittedStep(committedNote(), failedMarker(stepSqlHash("create table other (id int)")), appliedEngine(), {
  retries: 0,
  wrap: (error) => error
})
```

### fixed

```ts
() => resumeCommittedStep(committedNote(), failedMarker(committedNote().sqlHash), appliedEngine(), {
  retries: 0,
  wrap: (error) => error
})
```
