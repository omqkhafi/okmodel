# OKM1702

Unverifiable tenant SQL

## What happened

Raw SQL on a tenant table cannot prove the tenant predicate. A raw write is this. A raw read that does not select the primary key with ident is this. A typed raw call, raw(db, sql, params), on a client of a schema with tenancy is this.

## Fix

Use update or delete, or select the primary key with ident(name). For a typed raw call, use the table API, or pass trusted(client, "reason") to run the SQL without a tenant predicate on purpose.

## Escape hatches

Each hatch requires a human-written reason.

- unscoped()

- trusted()

## escape

A human-written reason is required.

unscoped()

trusted()

## Examples

### bad

```ts
async () => {

  class Row {
    id = "";
  }
  const scoped = connect(pool, {
    schema: schema({
      tenancy: columnTenancy({ key: "tenantId", type: "uuid" }),
      tables: [table("notes", { id: t.text().primaryKey(), title: t.text() })]
    })
  }).for({ tenantId: TENANT });
  await raw(scoped.notes, Row, "read", fragment`select ${ident("title")} from notes`);
}
```

### fixed

```ts
async () => {

  class Row {
    id = "";
  }
  const scoped = connect(pool, {
    schema: schema({
      tenancy: columnTenancy({ key: "tenantId", type: "uuid" }),

```
