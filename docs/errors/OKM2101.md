# OKM2101

Foreign key without an index

## What happened

No index starts with the columns of this foreign key, so a parent delete or key change scans the child table.

## Fix

Add an index that starts with the foreign key columns.

## Rule

`unindexed-foreign-key`

## Default

Level `warn`. Severity `medium`. Phase `check`. Evidence `static`.

## Safe alternatives

- Add an index that starts with the foreign key columns.

## page

Add an index that starts with the foreign key columns.

## Escape hatches

Each hatch requires a human-written reason.

- ignore

## escape

A human-written reason is required.

ignore

## Related

- OKM2102 Table without a primary key
- OKM2103 Filter or sort column without an index

## Examples

### bad

```ts
() => adviceCodes(schema({
  tables: [
    table("users", { id: t.identity() }),
    table("posts", { id: t.identity(), authorId: t.bigint().references("users") })
  ]
}))
```

### fixed

```ts
() => adviceCodes(schema({
  tables: [
    table("users", { id: t.identity() }),
    table("posts", { id: t.identity(), authorId: t.bigint().references("users") }, { indexes: (columns) => [index(columns.authorId)] })
  ]
}))
```
