# OKM1892

Shared migrations

## What happened

Two packages use the same migrations directory.

## Fix

Give each package its own migrations directory.

## Related

- OKM1890 Ambiguous config
- OKM1891 Workspace choice

## Examples

### bad

```ts
() => {
  refuseSharedMigrations(["packages/api", "packages/web"], "packages/web/migrations");
}
```

### fixed

```ts
() => {
  refuseSharedMigrations(["packages/api"], "packages/api/migrations");
}
```
