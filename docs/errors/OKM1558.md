# OKM1558

Invalid probe

## What happened

A probe is empty, is not one read-only SELECT, has more than one statement, or is declared on a step that stays inside a transaction.

## Fix

Write one read-only SELECT that returns a single boolean, and put it on a step that cannot share a transaction.

## Escape hatches

Each hatch requires a human-written reason.
