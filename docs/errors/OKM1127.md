# OKM1127

Relation order with distinct

## What happened

orderBy on a relation is not available with distinct or distinctOn.

## Fix

Order by a column of this table, or drop distinctOn.

## Related

- OKM1120 Unknown field
- OKM1121 Object as value
- OKM1122 Bad identifier
- OKM1123 Hidden field allowlist
- OKM1124 Operator mismatch
- OKM1125 Bad SQL fragment
- OKM1126 Parameter limit
- OKM1128 Relation order in aggregate

## Examples

### bad

```ts
async () => {
  await relationClient().tasks.find({
    distinctOn: ["title"],
    orderBy: { title: "asc", project: { name: "asc" } },
    limit: 5
  });
}
```

### fixed

```ts
async () => {
  await relationClient().tasks.find({
    distinctOn: ["title"],
    orderBy: { title: "asc" },
    limit: 5
  });
}
```
