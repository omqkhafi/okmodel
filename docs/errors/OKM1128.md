# OKM1128

Relation order in aggregate

## What happened

orderBy on a relation is not available in aggregate.

## Fix

Order by a groupBy field, count, or a select name.

## Related

- OKM1120 Unknown field
- OKM1121 Object as value
- OKM1122 Bad identifier
- OKM1123 Hidden field allowlist
- OKM1124 Operator mismatch
- OKM1125 Bad SQL fragment
- OKM1126 Parameter limit
- OKM1127 Relation order with distinct

## Examples

### bad

```ts
async () => {
  await relationClient().tasks.aggregate({
    count: !0,
    orderBy: { project: { name: "asc" } }
  });
}
```

### fixed

```ts
async () => {
  await relationClient().tasks.aggregate({ count: !0, orderBy: { count: "desc" } });
}
```
