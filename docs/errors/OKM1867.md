# OKM1867

Tenancy mode

## What happened

Tenancy schema or database is not supported by init yet.

## Fix

Pass --tenancy none, or --tenancy column.

## Related

- OKM1860 Feature refused
- OKM1862 Different driver
- OKM1863 Init decision
- OKM1864 User-modified file
- OKM1865 Unsupported project
- OKM1866 Plan hash mismatch

## Examples

### bad

```ts
() => {
  refuseTenancy("schema");
}
```

### fixed

```ts
() => {
  refuseTenancy("none");
}
```
