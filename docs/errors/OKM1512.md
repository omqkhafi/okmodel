# OKM1512

Drop column

## What happened

A statement drops a column. Stored values and the code that reads them are gone.

## Fix

Stop reading the column in an expand migration, then drop it in a later contract.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

-- okm-allow
