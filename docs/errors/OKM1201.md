# OKM1201

Validation not imported

## What happened

Validation is enabled but `okmodel/validate` was not imported.

## Fix

Import "okmodel/validate" before schema().

## Related

- OKM1200 Validation failed

## Examples

### bad

```ts
() => {
  refuseMissingValidation();
}
```

### fixed

```ts
() => {
  return schema({ tables: [table("notes", { id: t.text().primaryKey() })] }).catalog;
}
```
