# OKM1890

Observer keys

## What happened

writeObserver keys named a table that has no primary key or is not in the schema.

## Fix

Add a primary key on that table, or remove it from writeObserver({ keys }).

## Related

None.

## Examples

### bad

```ts
() => {
  const logs = table("logs", { body: t.text() }), app = schema({ tables: [logs] });
  assertObserveKeys(app, ["logs"]);
}
```

### fixed

```ts
() => {
  const logs = table("logs", { id: t.text().primaryKey(), body: t.text() }), app = schema({ tables: [logs] });
  assertObserveKeys(app, ["logs"]);
}
```
