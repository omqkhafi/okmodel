# OKM1552

Reprinted declaration

## What happened

A domain check or a LANGUAGE sql function body is stored differently from the text in the migration catalog.

## Fix

Write the check or the body the way Postgres prints it. The warning does not fail apply or migrate check. A reprinted domain check is sealed before the OKM1547 plan.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

## Examples

### bad

```ts
() => {
  const declared = schema({
    tables: [table("tasks", { n: t.domain("pos", t.integer(), "VALUE > 0") })]
  }).catalog, stored = {
    ...declared,
    objects: declared.objects.map((object) => {
      if (object.kind === "type" && object.identity.name === "pos" && "check" in object.definition)
        return { ...object, definition: { ...object.definition, check: "((VALUE > 0))" } };
      return object;
    })
  }, steps = planMigration({ before: empty, after: declared, name: "reprint" }).steps;
  return reprintHits(declared, stored, steps).map((item) => item.code);
}
```

### fixed

```ts
() => {
  const declared = schema({
    tables: [table("tasks", { n: t.domain("pos", t.integer(), "VALUE > 0") })]
  }).catalog, steps = planMigration({ before: empty, after: declared, name: "reprint" }).steps;
  return reprintHits(declared, declared, steps).map((item) => item.code);
}
```
