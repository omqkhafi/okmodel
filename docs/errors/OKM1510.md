# OKM1510

Unsafe migration

## What happened

A migration has an unresolved lint error, or an override with an empty reason or a code no statement in the step triggered.

## Fix

Change the statement so the finding is gone. An override must name a code that a statement in the step triggered, and the reason must not be empty.

## Escape hatches

Each hatch requires a human-written reason.

- -- okm-allow

## escape

A human-written reason is required.

-- okm-allow
