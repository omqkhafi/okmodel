# OKM1813

Extension defined twice

## What happened

The same extension definition was registered twice.

## Fix

Keep one definition. A second copy fails at build.

## Related

- OKM1810 Extension not declared
- OKM1811 Extension unavailable
- OKM1812 Feature version
- OKM1814 Extension change refused

## Examples

### bad

```ts
() => schema({
  tables: [table("notes", { id: t.text().primaryKey() })],
  extensions: [extension("citext"), extension("citext")]
}).catalog
```

### fixed

```ts
() => schema({
  tables: [table("notes", { id: t.text().primaryKey() })],
  extensions: [extension("citext")]
}).catalog
```
