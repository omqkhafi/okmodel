# OKM1124

Operator mismatch

## What happened

An operator does not apply to the column type.

## Fix

Use an operator the error lists for that column type. Search needs a column built for search, not a plain text column.

## Related

- OKM1120 Unknown field
- OKM1121 Object as value
- OKM1122 Bad identifier
- OKM1123 Hidden field allowlist
- OKM1125 Bad SQL fragment
- OKM1126 Parameter limit
- OKM1127 Relation order with distinct
- OKM1128 Relation order in aggregate

## Examples

### bad

```ts
async () => {
  await notesClient().notes.aggregate({ sum: ["title"] });
}
```

### fixed

```ts
async () => {
  await notesClient().notes.aggregate({ count: !0 });
}
```
