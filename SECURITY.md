# Security

## Reporting a vulnerability

The disclosure address is the [GitHub private advisory form](https://github.com/omqkhafi/okmodel/security/advisories/new).

Send the report there. Include the `okmodel` version, what an attacker can do, and a reproduction when you have one. Do not open a public issue, pull request, or discussion for a vulnerability. We acknowledge the report and ship a fix for the supported lines below.

Install and update guidance is in [Using OKModel safely](docs/using-okmodel-safely.md).

## Supported versions

OKModel supports the current 0.x minor and the previous minor. Today that is 0.10.x and 0.9.x.

| Version | Supported |
| ------- | --------- |
| 0.10.x  | yes       |
| 0.9.x   | yes       |
| older   | no        |
